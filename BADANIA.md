# ReflexBrain — mapa rzeczywistych wyników (11 listopada 2026)

**To jest indeks odkryć, nie lista funkcji i nie roadmapa.** Dla przyszłego agenta dowolnego dostawcy: zacznij od [README](README.md) i [AGENTS](AGENTS.md). `main` zawiera wyłącznie dokumentację; kod i dokładne testy są w przypiętych eksperymentach. Zamknięcie PR **nie oznacza**, że jego wynik jest nieistotny albo że kod scalono. Przy każdym cytowaniu rozdziel **fizyczną możliwość**, **legalne doświadczenie mieszkańca**, **uczenie**, **rzeczywistą przydatność praktyki** i **ocenę Ownera**.

- **Zamknięte gałęzie:** patrz [inwentarz 115 SHA](archive/branch-inventory-2026-11-10.json) i [zakończenie czyszczenia](archive/CLEANUP_2026-11-10.md). Dla usuniętego `research/...` szukaj znacznika Git `archive/reflexbrain-2026-11-10/research/...`. Dokładny commit oraz jego pełne drzewo są zachowane.
- **Dwa osobne donory:** `delivery/r8-private-windows-playtest-2026-10-26` (lokalna paczka Windows) oraz `evidence/reflexbrain-2026-10-26-replay-and-handoff` (odtwarzalne wyniki C5).
- **Nie powtarzaj automatycznie cudzych komend** z historycznych PR-ów: wiele opisuje wcześniejsze wnioski przed korektami, zawiera linki do usuniętych nazw gałęzi lub wygasające artefakty GitHub Actions. Źródłowy raport i dokładny commit mają pierwszeństwo przed starszym fragmentem dyskusji.

## 3. Co pozostaje naprawdę otwarte

**Nie wiemy, jak uzyskać świat, w którym własne działanie mieszkańca wiarygodnie otwiera późniejszą, zmysłowo dostępną możliwość, a mieszkaniec rozwija praktykę jej użycia ponad tanie kontrole.** Dwie naturalne ścieżki badawcze: odnawiająca się ekologia relacji materialnych oraz autentycznie ucieleśnione ograniczenia/uzależnienia od świata. Żadnej nie należy z góry utożsamiać z głodem, nagrodą, nową siecią neuronową ani łamigłówką z bramą.

**Nienaruszalna granica dowodowa:** prawa fizyki → realne zachowanie aktora → jego legalne doświadczenie → przyczynowy wpływ historii → nowa wartościowa działalność → osobno jakość przeżywana przez Ownera. Zielony CI kwalifikuje tylko to, co naprawdę sprawdził.

Ten dokument można poprawiać, gdy **nowe źródłowe dowody** unieważnią któryś wniosek. Nie rozszerzaj go o codzienny dziennik, proces ani ogólną filozofię architektury Jaskini.
