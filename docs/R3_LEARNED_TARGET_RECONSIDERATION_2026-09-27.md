## Decision

### REJECT as next learned target

Do **not** use row-level:

`private history + current report -> updateWorthy`

as the next learned ReflexBrain target.

This is a rejection of the **current next-step target formulation**, not a claim that learned temporal dynamics can never be useful.

### PRESERVE as deterministic actor-private state

Keep unresolved/settled bookkeeping as:
- actor-private;
- inspectable;
- deterministic;
- replaceable;
- outside World authority;
- outside learned semantic authority.

It belongs naturally to the host/local-live-brain side of the current charter until evidence shows learning adds something that deterministic continuity cannot.

### PRESERVE temporal evidence as context

Temporal state does not disappear from ReflexBrain research.

A future learned semantic mechanism may receive legal actor-private context such as:
- current matter;
- current report;
- whether equivalent evidence is already unresolved/settled;
- relevant private history summary.

But the learned component should not be rewarded merely for reproducing a state machine the host can calculate exactly.
