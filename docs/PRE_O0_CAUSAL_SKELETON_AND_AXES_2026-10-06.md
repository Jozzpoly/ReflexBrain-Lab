## Why this correction is needed

The candidate "organism families" combine several causal choices at once.

For example:
- Maintainer = authored normativity + recurring ecology + symbolic concern + local competence;
- Explorer = competence-based motivation + contingency learning + rich objects + developmental policy;
- Dyad = multi-actor ecology + private history + some unspecified motivation.

If one whole family succeeds, attribution is weak.

The campaign should therefore preserve a minimal causal skeleton and vary high-level research axes deliberately.

This is **not** a claim that the final organism is modular.

---

# Minimal causal skeleton

At the most neutral level, an artificial embodied actor requires only the following causal separation:

```
World_t
  │
  ├── physical coupling ──> Body_t
  │                        │
  │                        ├── proprioceptive/contact consequences
  │                        │
  │                        └── changes actor/world relation
  │
  └── observable relation(World_t, Body_t)
                           │
                           v
                      Private sensory evidence_t
                           │
                           v
                     Actor internal history/state_t
                           │
                           v
                   local action organization_t
                           │
                           v
                       Motor demand_t
                           │
                           └──────────── back into Body/World

Owner/world exogenous intervention ──> World/Body only
Research microscope ──> observes any plane, drives none
```

Learning, goals, beliefs, habits, prediction, values and ReflexBrain are **possible organizations inside this loop**, not prerequisites of the skeleton.

## Hard causal invariants

### K1 — physical mediation
Actor output cannot directly set authoritative World outcomes.

### K2 — epistemic mediation
Actor-internal state cannot update from hidden World truth except through an explicitly scoped perception oracle experiment.

### K3 — temporal persistence
Some actor-internal state may persist across ticks/encounters.

Without this, history cannot matter.

### K4 — exogenous causality
World/Owner changes can occur that are not generated by current actor output.

Without this, self/world discrimination is vacuous.

### K5 — researcher separation
Microscope/replay/oracle truth never silently becomes actor input.

### K6 — multiple possible futures
At relevant states, different actor/world interactions can lead to materially different future trajectories.

Without this, "choice", "affordance" and "meaning" are mostly decorative.

These invariants are stronger than yesterday's specific maintenance architecture and weaker than a cognitive theory.

# Dependencies and interactions

The axes are not independent in reality.

Important interactions:

### P × B
Perception of possible action depends on body capability.

### P × C
A controller may require a certain perceptual abstraction.

### M × E
Memory becomes valuable only when relevant world state can change or disappear outside current perception.

### N × E
Normativity has no useful expression if the world cannot alter relevant future possibilities.

### N × C
A concern does not determine how persistence/recovery should work.

### C × B
Body dynamics can make some control architectures easy or pathological.

### L × P
Learning quality depends strongly on what representation is learnable.

### L × N
Intrinsic learning pressure can become the organism's de facto normativity.

### S × M
Other actors make encounter history and identity more important.

### O × self/world prediction
Owner intervention is a powerful exafference test.

# Avoid the full factorial trap

The cross-product is enormous.

Do not test every combination.

Use **discriminative research probes**:

Choose two settings that differ in one high-value axis while holding enough else fixed to answer a concrete question.

Examples:

### Probe Q1 — object semantics leak
Compare P1 tracklets vs P3 semantic object kinds under the same simple ecology/policy concept.

Question:
does P3 solve the "intelligence" upstream?

### Probe Q2 — normativity source
Compare N0 authored concern vs N1 minimal viability or N4 habit while keeping world/body/perception similar.

Question:
does actor-relative significance improve or merely change labels?

### Probe Q3 — independent causality
Compare E1 recurrent process vs E2 independently changing process.

Question:
when do stale knowledge/self-world distinctions become naturally useful?

### Probe Q4 — morphology
Compare B0 disc vs B1 asymmetric body under the same local navigation/interactions.

Question:
does body shape create useful body-scaled affordances or only extra collisions?

### Probe Q5 — memory
Compare M0 history-only vs M2 relational memory under hidden relocation.

Question:
is symbolic object memory necessary or just convenient?

### Probe Q6 — action organization
Compare C1 behavior layers vs C2 explicit continuation under blocked progress.

Question:
which avoids both thrash and sticky persistence?

These are paper/probe questions before broad implementation.

# Strongest current consequence

The next decision should **not** be "which complete organism family wins?"

It should be:

> Which 4–6 foundational axis questions, if answered, would eliminate the largest amount of architectural uncertainty before implementation?

Candidate highest-information questions:

1. **N:** Does first organism need endogenous normativity beyond an authored concern?
2. **P:** How much perceptual ontology can be given without solving the problem?
3. **E/S:** How much independent world causality is needed for meaningful history?
4. **M:** What is the minimal private memory form that survives partial observability?
5. **C:** What produces temporal persistence/recovery without task-phase scripting?
6. **B:** Is E0 disc too weak a morphology for organism-level research?
7. **self/world:** Can action-consequence prediction supply a useful self/world seam?

These should drive F3 paper experiments and, if needed later, tiny isolated probes.

Implementation remains paused.
