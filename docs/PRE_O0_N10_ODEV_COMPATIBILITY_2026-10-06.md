# 2. What M0 offers to a developmental learner

## locomotion contingencies

- drive/turn -> body motion;
- body orientation -> local sensory flow;
- B1 morphology -> passage/contact differences.

## material interaction contingencies

- contact with light vs heavier loose bodies;
- pushing angle -> object/body outcome;
- object arrangement -> future accessibility.

## dynamic-process contingencies

- sweeper movement;
- sweeper/body/object collisions;
- state-dependent off-screen change.

## topology contingencies

- local material relation changes gate/access geometry;
- actor/world actions can alter later reachable structure.

## active-perception contingencies

- turning/moving changes occlusion;
- approaching changes relative sensory geometry;
- checking reveals hidden material state.

These are qualitatively different action-consequence families.

That is substantially richer than old empty Playground geometry.

# 6. Old Playground failure controls

O-DEV must explicitly attack old artifacts.

## OD1 — wall-clinging

Compare learning/progress with:
- repeated wall contact;
- free locomotion;
- object interaction.

A wall should not remain permanently attractive merely because context partition gives artificial progress.

## OD2 — noisy/unlearnable stimulus

Inject a research-only unpredictable visual/event process.

A good learning-progress mechanism should stop allocating excessive activity after it fails to become learnable.

Raw prediction-error curiosity should fail this control.

## OD3 — trivial easy process

Provide one immediately predictable action-effect relation.

Actor should not remain there forever after competence saturates.

## OD4 — context partition invariance

Small arbitrary changes to feature binning/representation should not radically reorder developmental trajectory.

If they do:
representation is the motivation.

## OD5 — track-token leakage

Changing temporary track tokens while preserving physical evidence must not reset competence as if a new world phenomenon appeared.

## OD6 — static-world ablation

Disable M0 independent processes.

Question:
does developmental trajectory lose meaningful diversity?

If not, ecology may be ornamental.

# 7. History / learning distinction

O-DEV should demonstrate more than memory-dependent behavior.

Required future evidence:

Same or closely matched current private observation/history query,
but competence/model parameters differ due to prior interaction,
leading to different prediction/action selection.

This is actual adaptation.

A simple last-known-location difference is not enough.
