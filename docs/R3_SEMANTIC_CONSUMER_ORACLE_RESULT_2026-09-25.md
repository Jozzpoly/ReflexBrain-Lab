## Question

Before choosing another learned objective, does an ideal actor-private semantic judgement have a downstream consumer that produces a useful causal difference inside zero-input autonomous pressure?

The tested consumer is deliberately narrow:

> Should Janek acknowledge this locally heard report, given the semantic meaning of his current actor-owned report matter?

The oracle is hand-authored research instrumentation. It is not ReflexBrain, not a final API and not automatic training supervision.

## Pressure construction

Janek continues ordinary workshop work while Ida emits local speech pressure.

Controls include:
- `ignore-all`;
- `respond-all`;
- cadence-only response with the same response budget;
- fixed depot-surface response;
- fixed courtyard-surface response;
- ideal joint semantic oracle.

World/body execution remains deterministic and separate from the oracle.

## Statement sensitivity

With fixed matter ids and identical pressure:
- baseline report meaning -> 50/50 relevant reports acknowledged;
- paraphrased report meaning -> 50/50 acknowledged;
- swapping workshop meaning onto the fixed report matter id -> 0/50 acknowledged.

This proves the oracle consumer is causally sensitive to `matter.statement` content rather than only matter identity.

## Same-id 2×2 relation falsifier

Two private-purpose worlds use the same matter ids and the same pressure timeline:
- report matter means depot-inspection reports matter;
- report matter means courtyard-flower reports matter.

The ideal relation must flip which surface receives a response.

Result:
- ideal semantic oracle relation accuracy: **1.000**;
- fixed depot-surface baseline: **0.500** across both private-purpose worlds;
- fixed courtyard-surface baseline: **0.500** across both private-purpose worlds.

Observed response pattern:
- depot-purpose oracle: depot 50 / courtyard 0;
- courtyard-purpose oracle: depot 0 / courtyard 50.

Therefore a fixed message surface or fixed matter id is insufficient for this bounded consumer. The useful decision is a joint relation between private purpose meaning and current evidence meaning.

## Causal consequence gate

A second pressure regime makes the required report persist until Janek acknowledges it.

Each four-slot block contains:
- one required report episode;
- two one-shot decoys;
- one repeat opportunity if the required report remains unresolved.

Correct acknowledgement removes a future Ida speech event. Ignoring required meaning therefore leaves real autonomous World pressure behind.

## Exact qualified claim

Within this authored autonomous pressure family, an ideal actor-private **joint semantic relation** can:

- resolve all recurring required report pressure;
- avoid all decoy acknowledgements;
- reduce unresolved World speech pressure relative to ignore-all and fixed-surface rules;
- avoid the 100 extra decoy acknowledgements paid by respond-all;
- adapt when the semantic meaning of the same matter id changes.

This is the first bounded causal evidence that a semantic/reflex judgement can have a useful downstream consumer in R3.

## What this does NOT prove

It does not prove:
- learned semantic competence;
- that any current representation can approximate the oracle;
- that oracle answers are valid training labels by default;
- that the current text pair is a hard learning benchmark;
- cross-actor, cross-domain or cross-policy generalization;
- throughput improvement — all tested modes completed 22 processing cycles;
- that R3 residents are alive in the Owner/product sense;
- that this response gate is the final ReflexBrain API or executive architecture.

## Critical next boundary

Do not train on the current tiny oracle fixture as-is.

The consumer value question is now partially answered. The next question is whether the needed relation can be **learned and generalized without merely memorizing authored surfaces or importing the oracle as the answer**.

Before model training:
1. build evaluation pressure with paraphrase / lexical counterfactuals and held-out relation surfaces;
2. include exact-pair, message-only, matter-only, token-overlap and simple structured controls;
3. preserve same-id purpose switching;
4. keep oracle output evaluation-only until a supervision-source audit explicitly justifies otherwise;
5. require transfer across at least one qualitatively different semantic pressure family before broader promotion.

A failed learnability/generalization result should kill or narrow the learned hypothesis, not invalidate the already-qualified consumer value.
