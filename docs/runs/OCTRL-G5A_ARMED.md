# Gate 2 — independent ecology behavioral value

Primary question:

> After the first lawful A/B private divergence caused by independent ecology, does the current frozen actor produce any subsequent ordinary motor-demand difference attributable to that lawful evidence difference?

Measure:
- first A/B private divergence tick;
- first A/B motor-demand divergence tick after that;
- actor/body trajectory divergence after lawful private divergence;
- final controller modes.

PASS requires:

- first motor-demand divergence exists;
- it occurs at or after first lawful private divergence;
- it is not caused by any hidden process signal or actor-process contact;
- B remains the matched static-world counterfactual.

FAIL if:

- A/B private evidence diverges lawfully but motor-demand traces remain identical through the frozen horizon;
- or any motor difference occurs before lawful private divergence.

INCONCLUSIVE if:
- variants cease to be matched for an unrelated mechanical reason.

Maximum Gate-2 claim:
