## One question

> Can the E01-qualified independent physical process compose with only static geometry + loose bodies so that ordinary physical consequences persistently change a locally relevant passage/relation, without introducing a second authored mechanism family?

---

## Why now

E01 proved the process can create persistent material change.

The next unresolved ecology question is whether that material change can become **locally consequential structure** rather than remaining an isolated displaced object.

This is the smallest step toward M0-Lite topology pressure.

---

## North-Star link

A future organism needs World consequences that alter what is physically possible or locally available without being scripted as semantic events.

E02 tests whether a tiny set of ordinary physical rules can create that kind of changing local structure.

It still does not test actor perception, meaning or life.

---

## Frozen inputs

- E01 shuttle process law and physical end-stop logic.
- Rapier deterministic substrate.
- No cognition.
- No perception/memory.
- No second active mechanism family.
- No plate/gate.
- No semantic topology state.

---

## Manipulated uncertainty

Only the **composition with static geometry + loose bodies**.

Allowed addition:
- one minimal chokepoint or passage geometry;
- one or a very small number of loose bodies whose physical position can matter to access.

---

## Allowed iteration

Allowed:
- chokepoint dimensions;
- blocker size/mass;
- placement;
- static wall geometry;
- E01 process placement/orientation if needed for composition.

Not allowed:
- changing the E01 process into a new control law;
- adding gate logic;
- adding scripted blocker states;
- adding a second motorized mechanism;
- adding actor intelligence.

---

## Evidence plan

Need a deterministic physical causal chain such as:

`E01 process -> loose blocker displacement -> passage becomes physically blocked/unblocked -> changed state persists`

The topology/access effect must be a consequence of ordinary collision geometry.

### Control

At minimum:
- same static geometry with E01 process disabled;
or
- same process without the blocker.

---

## Falsifier

E02 is **FAIL** if:

- a second authored mechanism is required;
- chokepoint state must be represented as semantic/scripted truth;
- the effect is too fragile/special-case to survive modest initial-condition variation;
- the E01 process remains mostly ornamental to access/topology;
- useful composition requires perception, actor control or task logic.

E02 is **INCONCLUSIVE** if:
- the physical state changes but the passage/access consequence cannot be unambiguously determined;
- instrumentation cannot distinguish real geometry-driven access change from a fixture artifact.
