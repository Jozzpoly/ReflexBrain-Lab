## One question

> Can one bounded, locally driven physical process continue without Owner/focal-agent input and produce persistent material displacement without reducing to global timer choreography?

---

## Why now

The current O-CTRL design assumes M0-Lite contains a useful independent non-agent process.

Before building:
- ecology topology;
- body morphology;
- perception;
- memory;
- concern;
- Local Brain;

we need to know whether that smallest source of exogenous material causality is real and usable.

If this fails, later organism work should not be built on M0-Lite by inertia.

ReflexBrain eventually needs an actor living under causal pressure that is not manufactured by Owner clicks or by the actor's own output.

E01 isolates the weakest possible version of that requirement:

## Evidence plan

Need at least one deterministic physical run where:

`bounded local drive -> shuttle motion -> physical contact -> loose-body displacement -> persistent changed material state`

and the interaction can alter the shuttle's actual timing/state relative to an unperturbed run.

The changed loose-body state must persist after immediate contact.

### Control / comparison

At minimum one of:

- same shuttle with no loose-body interaction;
- disabled/static shuttle;
- paired perturbed vs unperturbed initial condition.

The purpose is to show that observed material change comes from ordinary physical coupling, not a scripted phase.

---

## Falsifier

E01 is **FAIL** if:

- shuttle behavior is effectively open-loop timer choreography;
- useful persistent material change requires a second authored mechanism;
- contact dynamics are too unstable/pathological for later ecology use;
- the mechanism only looks interesting through debug state and is materially illegible at the ordinary surface;
- making it work requires solving later organism systems.

E01 is **INCONCLUSIVE** if the observation surface or physical instrumentation cannot distinguish real interaction-dependent dynamics from the scripted/open-loop alternative.
