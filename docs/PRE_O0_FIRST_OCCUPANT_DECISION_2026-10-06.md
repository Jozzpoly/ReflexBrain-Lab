# Pre-O0 First Occupant Decision — 2026-10-06

Status: **RESEARCH-SEQUENCE DECISION · IMPLEMENTATION STILL PAUSED**

## Blocker being resolved

The provisional substrate cannot be implemented responsibly without knowing what first occupant will justify it.

Candidates:
- T0 authored grounded concern;
- T1 developmental competence / learning-progress explorer;
- T2 sensorimotor habit organization.

The goal is not to crown a theory of life.

The goal is to maximize causal information while preserving a path toward a genuinely self-directed organism.

---

# External evidence relevant to the choice

## T1 developmental competence

Classic developmental robotics "Playground" experiments show that learning-progress-based intrinsic motivation can organize autonomous developmental sequences:
- focus on contexts where learning is progressing;
- move away from contexts already mastered;
- avoid contexts too unpredictable to learn;
- discover object and later social affordances without a manually ordered curriculum.

This directly overlaps with the positive direction seen in our own Persistent Playground.

But:
our own Playground exposed how strongly learning progress depends on representation/regionization.

Therefore T1 is scientifically high-value but not a safe substrate calibrator.

## T2 sensorimotor habit

Enactive robotics work demonstrates that plastic self-reinforcing sensorimotor systems can form and re-enact habits whose structure depends on the agent's sensorimotor modality.

This is highly relevant to endogenous continuity.

But:
our own Proto-Life history already showed how easily recurring internal/coupled dynamics can be mistaken for life.

T2 needs dedicated anti-cycle/attractor falsifiers before it can be trusted.

## T0 authored concern

Conceptually weaker as normativity.

But:
- easy to state;
- easy to inspect;
- private-knowledge failures are clear;
- body/world/perception/history failures are not hidden by learning dynamics;
- can qualify the substrate independently.

# Decision

Use a **two-stage occupant sequence**.

## Stage O-CTRL — T0 substrate-control organism

Purpose:

Qualify whether the new body/world/perception/private-history substrate can support:
- actor-owned temporal continuation;
- partial/private knowledge;
- material action;
- stale-memory correction;
- obstruction/recovery;
- independent ecology;
- scene rearrangement;

without hidden World truth.

The concern is explicitly authored.

The project must say so.

Allowed claim:

> the substrate can support a persistent embodied private agent pursuing one grounded authored concern.

Forbidden claim:

> this demonstrates endogenous normativity or solves the organism problem.

Owner "is it alive?" review is **not the promotion target** of O-CTRL.

O-CTRL is a causal calibration occupant.

## Stage O-DEV — T1 developmental challenger

On the same qualified substrate, replace or relax the authored concern with a developmental competence mechanism.

Purpose:

Ask whether self-directed learning of sensorimotor contingencies produces:
- richer actor-owned trajectory;
- useful competence development;
- history-dependent choice;
- spontaneous discovery of world regularities;
- new semantic pressure;

without the old Playground's region/noisy-TV/wall artifacts.

Compare against O-CTRL.

This is the first occupant that may genuinely challenge our model of what an organism needs.

## Stage O-HAB — T2 habit research only if earned

Do not implement concurrently.

Promote only if:
- O-DEV remains too metric-driven/task-like;
- we have strong anti-cycle instrumentation;
- a specific question about endogenous self-maintaining organization remains.

---

# Why T0 first is not a regression to R3

O-CTRL must differ materially from R3:

- physical Rapier body, not direct `move_to`;
- dynamic independent ecology, not policy-owned fixture pressure;
- lower-level private sensory evidence, not semantic object database;
- temporary perceptual tracks, not World identity;
- causal continuation through active local controller, not scripted activity phase;
- world rearrangement unknown to policy;
- Owner surface visually legible enough to observe causal behavior.

If these conditions are absent, O-CTRL is just R3 workshop again and should be rejected.

---

# What the authored concern should NOT be

Do not automatically reuse:
"keep material at maintenance site."

That is legacy inertia.

The concern must be selected only after ecology is defined.

Criteria:

- grounded in actor-private relations;
- does not reveal live World state;
- does not prescribe route/action;
- creates repeated but not constant pressure;
- interacts with independent world processes;
- leaves periods in which ordinary checking/exploration/recovery can occur;
- same concern works across rearranged world geometry.

Possible forms remain open.

# What T1 must improve over old Playground

Before T1 implementation, require:

### D1 — no coarse hand-authored 54-region table

Learning context must not be a tiny authored combinatorial state partition.

### D2 — learnability, not raw surprise

Unlearnable stochastic/noisy process must not dominate.

### D3 — continuous/private sensorimotor grounding

Learning uses body/sensory consequences available to actor.

### D4 — world diversity

At least several lawful action-consequence families.

### D5 — history matters beyond current error

Competence learning changes later ordinary behavior.

### D6 — no dedicated "training episode"

Development should arise through ongoing life.

### D7 — matched control

Compare with:
- random exploration;
- fixed policy;
- O-CTRL where relevant.

# Important experimental consequence

The first broad implementation should **not** be one giant final organism.

It should create one serious substrate and then support a deliberately small causal sequence:

1. O-CTRL qualifies substrate;
2. freeze substrate enough;
3. O-DEV tests developmental self-direction;
4. only after comparison decide whether the next organism architecture should inherit, combine or reject either.

This is not framework/plugin architecture.

Only build what the next concrete stage needs.

---

# Owner role

Owner should eventually see both surfaces, but with different questions.

## O-CTRL Owner question

Not:
"does this feel alive?"

Instead:
- does the body/world feel rule-governed?
- does ignorance/search look coherent?
- does it seem to own a persistent authored trajectory?
- do perturbations have believable consequences?

## O-DEV Owner question

Now broader:
- is there a qualitatively different sense of self-directed activity?
- does history/learning create recognizable developmental change?
- is behavior interesting for reasons beyond random motion/task repetition?
- does it discover things rather than merely execute them?

Machine evidence remains separate.
