# Pre-O0 Ecology Deep Dive — 2026-10-06

Status: **FOUNDATIONAL OPEN QUESTION · MAP SIZE IS NOT ECOLOGY**

## Core correction

Yesterday's diagnosis "E0 arena is too small" was true but incomplete.

The deeper variable is:

> **causal richness per unit of understandable world**, not spatial area.

A large static map can remain cognitively empty.

A small world can be rich if it contains several independent, persistent, partially observable processes whose intersections alter the actor's possible continuations.

---

# 1. What a useful micro-ecology must provide

## EC1 — persistence

World changes survive after the actor leaves.

Moved object stays moved.
Blocked route stays blocked.
Consumed/transformed material remains changed.

Without persistence, history has little value.

## EC2 — partial observability

Relevant change can happen outside current perception.

Without this, memory is decorative.

## EC3 — independent causality

At least some world change is not generated by the actor or Owner.

Without this, self/world distinction is trivial and Owner manufactures life.

## EC4 — controllability

Some world variables can be changed by actor action.

Without this, the actor is only an observer.

## EC5 — multiple continuations

Several materially possible responses exist in relevant states.

Without this, policy choice is decorative.

## EC6 — delayed consequence

At least some interaction matters beyond the immediate tick.

Without this, history and prediction remain shallow.

## EC7 — heterogeneous lawfulness

Different things/processes respond differently for physical/causal reasons.

Without this, affordance learning has little substrate.

## EC8 — actor-independent continuation

World processes continue while actor is elsewhere.

Without this, ecology is an extension of the actor's animation.

---

# 2. Causal richness dimensions

Do not conflate these.

### spatial topology
rooms, loops, chokepoints, occlusion, alternate routes.

### material state
movable objects, mass, support, carried state, blockage.

### temporal processes
growth, depletion, motion, cooling/heating, opening/closing, transformation.

### relational processes
one object affects another:
weight triggers plate;
flow transports object;
door alters reachability;
carrier changes passage.

### independent actors/processes
another body or autonomous mechanism creates events.

### latent state
world state not immediately visible but inferable through consequences.

### irreversible / costly change
some actions cannot be instantly undone.

Use sparingly; irreversible consequences create history.

---

# 3. A world should generate questions naturally

A strong ecology makes the actor face questions such as:

- Where did the thing I saw earlier go?
- Is this route still usable?
- Did my action cause that movement?
- Is this object actually movable by my current body?
- Is waiting useful here?
- Should I continue, search, re-check or abandon?
- What changed while I was elsewhere?
- Is this new object/process like something I previously interacted with?
- Does another moving body explain this change?
- Can I alter the environment to make a future action easier?

If these questions never arise without test harness intervention, ecology is too poor.

# 4. Candidate world processes

These are ingredients, not a final map.

## W-A — material source/sink cycle

A source exposes material.
Another process consumes/transforms it.

Strengths:
- persistent pressure;
- object location/history;
- carrying/manipulation.

Risk:
- workshop/task-bot lineage.

Use as baseline only.

## W-B — moving obstruction / mobile mechanism

A body/process moves through space according to lawful local dynamics.

Examples:
- pendulum;
- sliding gate;
- slow sweeper;
- conveyor;
- rolling body on a loop.

Strengths:
- exogenous motion;
- reafference/exafference;
- timing and interception;
- temporary route availability.

Risk:
- periodic timing code.

Mitigation:
- event-driven phase;
- interaction-dependent timing;
- multiple initial conditions.

## W-C — topology changer

A door/gate/bridge changes passability due to local physical state.

Examples:
- pressure plate;
- weighted gate;
- movable blocker;
- object-supported bridge.

Strengths:
- world state changes future affordances;
- actor can restructure future possibilities;
- memory of topology can become stale.

Risk:
- puzzle fixture.

Keep mechanism general and reusable.

## W-D — field / gradient process

A local field changes through space/time:
- temperature;
- light;
- signal;
- energy availability.

Strengths:
- continuous sensorimotor relation;
- supports active sampling;
- can ground homeostatic variants.

Risk:
- invisible scalar world.

Must have interpretable material/sensory consequence.

## W-E — transformation process

Objects can change state through world interaction:
- raw -> processed;
- hot -> cool;
- charged -> discharged;
- wet -> dry.

Strengths:
- delayed consequences;
- object history matters.

Risk:
- recipe/task graph.

Avoid semantic phase labels in actor perception.

## W-F — non-cognitive autonomous body

A simple moving physical process/body with no private memory.

Strengths:
- independent causal line;
- collisions;
- object displacement;
- off-screen change;
- cleaner than second full actor.

Risk:
- random obstacle theatre.

Motion must be lawful enough to learn.

## W-G — second simple actor

Independent sensorimotor policy and private trajectory.

Strengths:
- richest actor-relative events;
- same event/different history;
- genuine distributed world activity.

Risk:
- complexity and anthropomorphic over-reading.

Hold until simpler independent processes are insufficient, or test as explicit comparison.

# 5. Timescale matters

Previous experiments often had one dominant tick scale.

A richer ecology should contain at least 2–3 natural timescales:

### fast
collision, movement, immediate sensory consequence.

### medium
local continuation, obstacle change, object transport.

### slow
resource regeneration, internal capability drift, habit/memory consolidation, world process.

Why:

Meaning often depends on interaction across timescales.

Example:
a collision is fast;
a route becomes undesirable after repeated collisions;
a long-term object relocation changes future routine.

Do not create slow processes merely through arbitrary countdown timers.

Prefer causal accumulation/state change where possible.

---

# 6. Avoid timing-code ecology

R3 already exposed phase/timing shortcuts.

Any periodic process should face:

- randomized start phase;
- variable period;
- perturbation that resets/delays process;
- same elapsed time with different material state;
- same material state at different elapsed times.

Actor policy should respond to perceptible state, not global tick.

---

# 7. Ecology as curriculum

The world itself can create a developmental ordering without a scripted curriculum.

Possible principle:

Early interactions are locally obvious and low-cost.
Later opportunities require:
- remembering;
- combining known effects;
- checking uncertain state;
- adapting to changed body/world relation.

This is different from:
`level1 -> level2 -> level3`.

The same world can expose different affordances as competence changes.

This is especially relevant to:
- developmental exploration;
- body-scaled affordances;
- future ReflexBrain semantic pressure.

---

# 8. Spatial structure

Do not freeze a map yet.

Required qualitative properties worth testing:

### loop
at least one topological cycle, so route choice exists.

### occlusion
some relevant region hidden from another.

### chokepoint
body/object placement can alter passage.

### open area
enough space to assess locomotion.

### local landmark diversity
distinct physical configurations useful for orientation.

### rearrangeability
some objects/processes can alter local topology.

A 2–4 region micro-world could be enough if these relations exist.

---

# 9. Owner relation to ecology

Owner should be able to:

- watch;
- rearrange selected physical objects;
- perturb one world process;
- create an unexpected but World-legal state.

But core ecology must keep producing events without Owner.

A useful test:

> leave the world running for several minutes with Owner absent, then return.

Questions:
- what materially changed?
- what did actor experience?
- what did actor miss?
- what new history exists?

If answer is "nothing important", ecology is too poor.

---

# 10. Environment-generalization test

Three fixed maps are weak.

Better:

### authored seed set
3–5 human-understandable layouts.

### constrained rearrangement
same mechanisms, different geometry/initial state.

### Owner-created unknown arrangement
Owner moves legal objects/obstacles without policy changes.

### held-out mechanism composition
same primitives combined in a new way.

Policy never receives scene ID.

Researcher can still use seeds for reproducibility.

# 11. Strong candidate ecology comparison

Before implementation, compare on paper:

## Ecology E-A — static play yard
rich objects, little autonomous world change.

Tests:
sensorimotor development.

## Ecology E-B — dynamic mechanical yard
same objects plus 1–2 independent mechanisms/topology changes.

Tests:
self/world distinction, stale memory, active perception.

## Ecology E-C — viability habitat
dynamic field/resources linked to body capability.

Tests:
normativity.

## Ecology E-D — dyadic yard
one other simple actor.

Tests:
independent trajectories/social-relational meaning.

Hypothesis:

**E-B may be the best foundational ecology** because it adds independent causality without immediately importing task, metabolism or social complexity.

This is not a decision yet.

# 12. Possible "small rules, rich world" direction

A particularly attractive long-term direction is a world where a few mechanisms compose:

- rigid-body contact;
- occlusion;
- movable topology;
- one or two autonomous physical processes;
- object transformation;
- local fields;
- actor interventions.

Richness should come from intersections of these mechanisms rather than content count.

This aligns with the project-wide aspiration:
**few local rules -> many consequential combinations**.

But it must be demonstrated, not assumed.

---

# Current ecology conclusion

Do not design O0 as "bigger arena with source and site".

The first serious world candidate should be judged by:

- independent causality;
- persistent material change;
- partial observability;
- multiple possible continuations;
- cross-timescale consequences;
- compositional mechanisms.

Map size is secondary.

The strongest current research candidate is a **small dynamic mechanical ecology** that can later host different normativity families without changing its fundamental rules.
