## R0 — semantic shadow bootstrap

### What it actually tested

R0 asked whether a fast local semantic provider could sit between actor-private perception and local execution without controlling the World.

Technical ingredients:
- actor-private state compiler;
- zero-authority shadow evaluation;
- same-state provider comparison;
- raw semantic output separated from stabilized temporal dynamics;
- deterministic/non-interference checks;
- browser-local model path.

### Keep as durable donor

**Method / invariant**
- shadow candidate must not mutate World/body truth;
- same-state A/B before interpreting closed-loop divergence;
- separate instantaneous judgement from temporal realization;
- hidden World facts must not enter actor-private inference.

### Keep only in history / recover on demand

**Code**
- `src/shadow-runner.ts` — useful pattern, but tied to old types;
- local browser model client/worker — useful precedent for future local inference.

### Retire from active architecture

- `attentionPlayer / interruptCurrent / socialRelevance / novelty / threat / deeperCognition` score vector;
- player-centric private-state compiler;
- old reflex smoothing thresholds;
- rule-provider behaviour.

Reason: later R1 evidence showed the score ontology is not coherent enough, and later project direction requires an already-living organism before semantic appraisal.

## R1 — frozen representation / OOD / geometry campaign

### What it actually tested

R1 stopped asking a small generative model to directly "be the reflex" and tested whether a frozen MiniLM representation plus exact actor-private structured channels could support bounded semantic distinctions.

It also hardened:
- lexical counterfactuals;
- isolated per-state embedding;
- batch-layout invariance;
- OOD holdouts;
- relation geometry;
- train-direction coherence;
- transparent prototype and linear heads.

### Keep as durable donor

**Method / infrastructure**
- browser/WebGPU frozen encoder precedent;
- pinned model + revision + dtype + isolated batching;
- explicit structured channels for exact actor-private facts instead of forcing geometry/kinematics through language;
- lexical shortcut controls;
- OOD as falsifier, not future TRAIN data;
- relation-geometry audits before increasing head capacity;
- transparent weak heads as diagnostic instruments.

### Candidate code donors, but do not carry actively

- `src/r1/encoder-worker.ts` — local WebGPU embedding runtime pattern;
- `src/r1/relation-geometry.ts` — useful diagnostic math;
- selected encoder contract/client patterns.

Recover by ref when a learned ReflexBrain stage is earned.

### Retire from active architecture

- five scalar appraisal axes as ontology;
- R1 structured feature schema;
- prototype/linear head as default ReflexBrain;
- old training augmentation corpora;
- assumption that semantic competence should be solved before organism pressure exists.

## R2 — causal organism campaign

### What it actually tested

R2 tried to replace score-centric research with a causal organism and introduced a much stronger epistemic decomposition.

Its Owner-facing implementation failed categorically as a click-driven research toy.

### Keep as durable donor

**Method / conceptual kernel**
- `World truth != private evidence != interpretation != policy != authority`;
- ongoing activity is first-class;
- challenge families should test causal distinctions rather than internal labels;
- oracle-before-learned-replacement;
- Owner-test direction as anti-drift pressure;
- temporal readiness;
- causal provenance.

### Candidate code donors

- `src/r2/causal-microscope.ts` — neutral world/private provenance view;
- `src/r2/oracle-ladder.ts` — explicit research-only substitution boundary;
- parts of `src/r2/causal-contracts.ts` as terminology inspiration.

Do **not** transplant these contracts wholesale. `OngoingActivity.phase` and generic causal payloads were research scaffolds, not proven O0 ontology.

### Retire from active architecture

- R2 live clicker;
- challenge UI;
- old "living specimen" implementation;
- any assumption that richly instrumented causal bookkeeping is organism evidence.

## R3 — autonomous pressure / semantic-supervision campaign

### What it actually achieved

R3 corrected R2's click-driven pressure by building a zero-input autonomous research host.

It accumulated the largest evidence base in the project:
- local sight/hearing;
- private object/actor memory;
- checked absence;
- continuing matters;
- autonomous material and social pressure;
- causal first-divergence comparison;
- matter ablation;
- semantic consumer oracles;
- supervision-provenance audits;
- purpose grounding;
- recurrent pressure;
- many representation/relation falsifiers.

It also became extremely large and benchmark-heavy.

### Highest-value durable donors

**Private epistemics**
- last-known state;
- checked absence invalidation;
- private memory updated by observation;
- distinction between World event, private observation, memory and decision.

**Causal research**
- first divergence across observation/private state/decision/outcome;
- paired ablation as a research microscope;
- no hidden World input after perception boundary;
- supervision provenance must be audited;
- paraphrase/lexical controls;
- causal consumer value before learning a replacement.

**Grounded purpose**
- a continuing concern must have a causal structured anchor in the world;
- natural-language statement alone is not grounding;
- same ID / different causal structure and wording-invariance tests are valuable.

### Candidate code donors

Recover selectively, not as architecture:
- `src/r3/resident-agent.ts` — especially checked-absence logic;
- `src/r3/counterfactual-evidence.ts` — first-divergence comparison pattern;
- `src/r3/life-world.ts` — only as reference for perception/event provenance;
- `src/r3/grounded-purpose-structure-run.ts` — as a falsifier pattern for grounded purpose.

### Do not reuse as O0 substrate

- `life-world.ts` movement model: direct `move_to` position stepping is not the E0 material body;
- hard-coded resident IDs and material kinds;
- matter lifecycle as universal actor ontology;
- R3 fixture policies;
- semantic corpus builders;
- direct-cosine / learned-head probe pages;
- semantic-pressure fixtures as the first new organism.

### Evidence-only archive

The majority of R3's 50+ contract/result documents, corpus builders and narrow tests are valuable as falsification history but should not remain in the active O0 build/test surface.

## Pruning judgement

The current recovery branch inherits ~230 files and `yarn check` still type-checks all historical `src`, runs all historical tests, and Vite builds the R3 probe pages.

This is no longer desirable.

After one archival checkpoint, the active O0 line should remove historical R0/R1/R2/R3 implementation code, narrow probe pages and their tests from the active worktree.

This is **not destruction**:
- exact branches/SHAs remain;
- the salvage map records what to recover;
- git history remains;
- future donors can be cherry-picked or reimplemented with evidence.

The purpose of pruning is to prevent accidental architectural inheritance and reduce CI/agent attention cost.

## Anti-loss rule

Do not delete or rewrite historical branches merely because the active O0 line no longer carries their files.

The project should be clean forward and rich backward.
