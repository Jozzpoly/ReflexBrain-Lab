## Highest-risk hidden assumptions

### 1. The world is a task fixture

Yesterday's maintenance loop risks giving the organism a reason to exist only because the experimenter authored a job.

This may be acceptable as scaffold, but cannot silently become "normativity".

### 2. Perception arrives already objectified

Stable object identity, kind, bearing and distance can turn a difficult embodied problem into table lookup.

Need an explicit perceptual-abstraction boundary.

### 3. Memory is a symbolic database

R3's object beliefs were useful research substrate. Carrying them forward unchanged could predefine object permanence, identity and relevance.

### 4. Navigation becomes hidden intelligence

Exact geometry, target distance, local rays and search logic can collectively become the smartest part of the organism while appearing "mechanical".

### 5. Generalization becomes fixture-family generalization

Three designed scenes can produce another benchmark-shaped creature.

Need open rearrangement or procedural material variation not visible to policy.

### 6. Normativity is outsourced

An authored concern can yield coherent persistence without the organism having anything genuinely at stake.

Need compare task, viability, habit and competence-based sources of concern.

### 7. We equate autonomy with continuous motion

Zero-input movement is necessary only for some ecologies. A real organism may sometimes wait, rest, hide or preserve state.

"Activity" should mean actor-owned causal continuation, not nonzero velocity.

## What survives F0 with highest confidence

1. persistent embodied direction;
2. Owner is not heartbeat;
3. private epistemics matter;
4. lived history must be able to change later ordinary behaviour;
5. material body/world consequences matter;
6. debug/research truth cannot drive actor;
7. scene-specific hidden scripts are disallowed;
8. instrumentation must remain subordinate to organism surface;
9. learned ReflexBrain returns only when substrate produces repeated residual semantic pressure;
10. implementation remains paused.

## F0 conclusion

Yesterday's O0 is useful as a **dense hypothesis bundle**, not as an implementation contract.

The campaign should next compare alternative organism families that intentionally make different choices on:
- source of normativity;
- perceptual abstraction;
- memory representation;
- number of autonomous causal actors/processes;
- Local Brain organization;
- body morphology.

Do not "repair" the old O0 assumption by assumption. Construct genuinely different families.
