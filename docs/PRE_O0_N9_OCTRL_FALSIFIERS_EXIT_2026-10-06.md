# Q0 — zero-Owner causal continuation

## Setup

Run M0 with no Owner interaction.

The mechanical shuttle/process continues.
The actor begins from legal initial private evidence.

## Required

- actor produces a persistent concern trajectory when its concern is privately unresolved;
- world continues changing independently;
- actor can become quiescent if it privately supports concern satisfaction;
- independent world process can later change material configuration without Owner.

## FAIL if

- actor requires clicks/input to continue;
- all relevant world change stops with actor;
- actor is always moving solely to satisfy "autonomy";
- concern state updates from hidden World satisfaction.

## Claim if PASS

Only:
**zero-Owner persistent authored concern exists inside an independently changing world.**

# Q1 — hidden lawful target displacement / no epistemic leak

## Setup

Actor has current private evidence that marked body is settled at dock.

Actor moves/looks elsewhere such that dock/target are occluded.

M0 world process physically displaces the marked body while actor has no legal sensory access.

No teleport or semantic Owner event is supplied.

## Required before new evidence

- actor private relation belief does not update solely because World changed;
- active controller does not immediately route to true new target location;
- no P1 track survives full occlusion as hidden identity/position oracle.

## FAIL if

any decision/state diverges due to hidden target displacement before actor-private sensory/history divergence.

This is a first-divergence test.

---

# Q2 — checked contradiction and reacquisition

Continuation of Q1.

Actor later checks the privately expected relation/location.

## Required

- expected perceptual evidence fails;
- private relation becomes unsupported/unknown or contradicted;
- concern persists while factual hypothesis changes;
- actor enters bounded reacquisition using only private evidence;
- later lawful perception of the marked body can update private hypothesis;
- restoration can resume.

## FAIL if

- old memory persists despite direct contrary evidence;
- actor magically jumps to true location;
- generic search only succeeds because it sees hidden map/route;
- concern itself is deleted when one factual hypothesis fails.

# Q3 — irrelevant matched perturbation

## Setup

Match Q1 in magnitude/timing of physical disturbance, but move:
- a distractor body;
- or perturb actor/world in a way that provides no evidence about marked-body ↔ dock relation.

## Required

- actor may react locally to physical/sensory disturbance;
- concern target-location/dock belief must not update as if Q1 occurred;
- broad adaptation/reset must not occur.

## FAIL if

large generic surprise rewrites concern memory or causes global search.

Purpose:
separate relevant private evidence from generic novelty.

# Q4 — material restoration / no action oracle

## Setup

Actor legally observes that marked body is out of dock.

## Required

- restoration proceeds through B0/B1 body motor demand and physical contact;
- no direct object position set;
- no semantic `push(target)` World action;
- unsuccessful contact can fail visibly;
- relation belief changes only after legal evidence of resulting state.

## FAIL if

intended action is treated as successful regardless of physical outcome.

# Q5 — temporary obstruction vs persistent obstruction

Two matched runs.

### Q5a temporary

Block current approach briefly, then clear.

Required:
- controller does not immediately abandon concern/approach;
- avoids framewise thrash;
- resumes when evidence supports continuation.

### Q5b persistent

Keep obstruction.

Required:
- repeated lack of progress/contact accumulates contradiction;
- local recovery changes approach;
- actor does not push forever if another locally discoverable continuation exists;
- actor may eventually remain unresolved/uncertain if no legal solution is found.

Important:
success is not mandatory if the current private competence genuinely cannot solve layout.

Honest unresolved failure is preferable to hidden oracle.

## FAIL if

- oscillatory thrash;
- eternal identical pushing;
- magic alternate route.

# Q6 — relevant private-history pair

Construct paired deterministic runs that reach approximately matched:

- current visible P0/P1 evidence;
- body pose/motion;
- current World local geometry;

but differ in relevant private history.

Example:
one run has just checked old target location and found absence;
the other has not.

## Required

- private state differs before controller/motor demand diverges;
- later behavior may differ for that reason;
- microscope traces first divergence correctly.

## Control

Matched irrelevant-history difference should not reproduce the same decision divergence.

## Claim if PASS

**private history is causally active in ordinary behavior.**

Not:
learning.

- one legal Owner-created arrangement unknown when policy logic was authored.

- no added layout-specific waypoint/branch;

policy needs a new scene-specific exception to perform the same concern.

This is anti-fixture evidence, not a generalization benchmark score.

1. hard machine boundaries pass;
