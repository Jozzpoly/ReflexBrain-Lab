# Pre-O0 N2 — Independent Dynamic World vs Autonomous Peer — 2026-10-06

Status: **CONVERGENCE COMPARISON · SOCIALITY REMAINS OPEN**

## Compared substrates

### D0 — dynamic non-agent ecology

One focal actor.

World contains at least one independent lawful process/body that:
- changes material state without focal action;
- can continue off-screen;
- can alter route/object relations;
- is physically observable;
- has no private memory or adaptive policy.

### D1 — autonomous peer

Replace or supplement that process with another embodied actor that:
- has its own private sensing/history;
- produces its own actions;
- reacts to the focal actor/world;
- continues without Owner.

No language/social semantics required.

---

# Scenario IC1 — hidden off-screen change

A relevant object/route changes while focal actor cannot observe it.

### D0
Already produces:
- stale knowledge;
- checked absence;
- active checking;
- exogenous causal change.

### D1
Also produces these.

Additional value only if peer's private history changes *which* hidden event occurs.

Verdict:
sociality not necessary for basic private epistemics.

---

# Scenario IC2 — matched self/world displacement

Same sensory change caused by:
- focal self-motion;
- independent mover/peer motion.

### D0
Sufficient for reafference/exafference research.

### D1
No foundational addition unless reciprocal adaptation matters.

Verdict:
D0 sufficient.

---

# Scenario IC3 — reciprocal response

Focal actor changes behavior toward moving entity.

### D0
Process trajectory does not adapt to focal action except through physical mechanism.

### D1
Peer may change its behavior because focal actor changed.

This creates:
`I act -> you adapt -> I perceive consequence -> I adapt...`

This reciprocal causal loop is qualitatively new.

Verdict:
D1 uniquely tests interactional reciprocity.

---

# Scenario IC4 — same current view, different encounter history

### D0
Dynamic mechanism can have state/history, but not private interpretation.

Focal actor's history can still differ.

### D1
Both actors can carry different private histories.
Same visible configuration may embed two hidden trajectories.

This creates richer actor-relative ambiguity.

Verdict:
D1 adds genuine new pressure.

---

# Scenario IC5 — live vs replay

Use same recorded peer path.

Condition A:
live responsive peer.

Condition B:
replayed non-responsive path.

If focal behavior differs only in A after reciprocal interaction, that is evidence that live coupling matters.

This test has no analogue in pure D0 because D0 is intentionally non-responsive.

Verdict:
strong discriminator for whether sociality adds value.

---

# Scenario IC6 — causal diagnosis

Something unexpected happens.

### D0
Potential causes:
- independent mechanism;
- focal action;
- physical interaction.

Relatively clean.

### D1
Potential causes include:
- peer observation;
- peer private history;
- peer local policy;
- reciprocal loop.

Much harder to diagnose.

Verdict:
D0 is better first microscope.

---

# Scenario IC7 — Owner absent for long period

### D0
World continues independently.
Good test of stale memory and organism trajectory.

### D1
World can develop encounter history elsewhere.
Potentially much richer.

But:
richness can conceal weak focal policy.

Verdict:
D1 higher ceiling, D0 cleaner baseline.

---

# Scenario IC8 — semantic pressure

What later ReflexBrain-relevant ambiguity appears?

### D0 examples
- Did this unexplained change invalidate my ongoing activity?
- Is this recurrent dynamic process relevant to my concern?
- Is a novel perturbation worth investigating?
- Is apparent obstacle temporary or persistent?

### D1 examples
All above plus:
- Is the peer's behavior incidental or responsive to me?
- Does this encounter relate to prior interaction?
- Is the peer helping/blocking/competing by accident or persistent pattern?
- Does a signal/action refer to my current concern?

Verdict:
D1 naturally creates richer semantic pressure.

# Critical insight

A second actor is **not needed to solve the first foundational deficits**:

- exogenous world change;
- partial observability;
- stale memory;
- self/world distinction;
- obstruction/recovery;
- persistent off-screen causality.

A dynamic non-agent ecology can generate all of these with much cleaner causal attribution.

What D1 uniquely adds is:
- reciprocal responsiveness;
- dual private history;
- emergent dyadic dynamics;
- proto-social semantic pressure.

Those are extremely valuable, but they are a **second qualitative pressure**, not required to establish the first organism.

---

# Paper verdict

Current best first substrate choice:

> **Start with D0 — one focal actor inside a genuinely dynamic, independently changing mechanical ecology.**

Reasons:
- maximizes causal clarity;
- prevents social spectacle from hiding weak embodiment;
- already supports all core private-history/self-world questions;
- cheaper to vary/rearrange;
- provides a clean baseline for later D1 comparison.

But architecturally preserve a **peer insertion seam**:
the world should not assume all moving causes are non-agent mechanisms.

## Promotion trigger for D1

Introduce the autonomous peer early when:
- D0 organism is materially coherent;
- private memory/self-world distinction are qualified;
- remaining semantic pressure is too task/mechanical;
- we specifically want to test reciprocal actor-relative meaning.

Then compare:
D0 mechanism vs D1 live peer under matched gross physical conditions.

This gives sociality a real scientific role rather than making it decorative life feel.
