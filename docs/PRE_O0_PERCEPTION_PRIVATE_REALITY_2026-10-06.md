# Pre-O0 Perception and Private Reality Deep Dive — 2026-10-06

Status: **FOUNDATIONAL OPEN QUESTION · STRUCTURED VISION NOT PROMOTED**

## Core problem

The first organism must not require solving computer vision.

But it also must not receive a semantic database disguised as vision.

The useful question is:

> What synthetic sensorium gives enough lawful body-world information for agency research while leaving identity, persistence, affordance and meaning partly dependent on interaction/history?

---

# 1. Separate four levels that yesterday collapsed

## World entity

Researcher/physics truth:
- exact body/entity identity;
- exact position/shape;
- material parameters;
- authoritative state.

The actor must not consume this directly.

## sensory return

What current body/environment relation produces now.

Examples:
- occupied visual direction;
- local surface distance;
- motion in egocentric coordinates;
- contact force;
- auditory event direction/intensity.

No persistence is implied.

## perceptual track

Actor-private attempt to say:
"this current sensory structure appears continuous with that recent one."

May be:
- temporary;
- wrong;
- split;
- merged;
- lost under occlusion.

Track identity is not World identity.

## remembered entity/hypothesis

Actor-private historical continuity across absence.

This is already a cognitive/memory construction.

Do not collapse all four into `visibleObject{id,kind,x,y}`.

---

# 2. Practical middle ground — synthetic perception without raw pixels

Raw image learning would consume the project.

Instead build physically derived **sensor primitives**.

Candidate visual return:

- egocentric angular segment / blob;
- approximate angular width;
- near/far/depth-like signal;
- relative motion / optic-flow-like change;
- simple appearance signature;
- occlusion boundary.

Possible appearance signature:
- shape class only if visually intrinsic;
- color/material visual signature;
- size estimate;
- texture code.

Avoid semantic roles:
- source;
- food;
- maintenance token;
- obstacle;
- useful;
- heavy;
- dangerous.

Physical properties not visible should require interaction.

---

# 3. Tracklets as a promising abstraction boundary

Candidate P1:

While a sensory blob evolves continuously in view, the perception layer maintains a temporary actor-private `trackToken`.

Properties:
- token is generated by actor perception, not World ID;
- continuity uses local motion/appearance consistency;
- token can be lost behind occlusion;
- reappearance may receive:
  - same token if confidence is high;
  - new token;
  - uncertain association.

This gives ordinary Local Brain something more tractable than raw rays without handing it permanent object ontology.

World ID remains microscope-only.

## Why this matters

It permits experiments such as:

- two visually similar objects cross;
- object disappears behind wall;
- Owner swaps identical objects;
- object changes appearance;
- actor turns away and returns.

A symbolic World-ID percept would silently solve all of these.

---

# 4. Object permanence should have a scope

Possible first-level continuity:

### immediate persistence
continuous visual track.

### short occlusion expectation
track may persist briefly behind predictable occlusion.

### historical identity
"the thing I encountered earlier" after long absence.

These are different competences.

Do not require all at first.

R3's checked absence can be reinterpreted:

> a remembered hypothesis about a previously encountered entity/location loses support when the actor actively checks the expected sensory relation and it is absent.

This principle survives even if memory is not object-symbolic.

---

# 5. Active perception

Perception should change when the actor acts.

Useful consequences:

- turning changes visible structure;
- approaching changes angular/depth relation;
- moving around an object reveals geometry;
- contact reveals properties vision cannot;
- checking behind a wall is an action, not a free query.

This means some uncertainty is resolved through behavior.

The organism can therefore have **epistemic action** without a POMDP planner:
ordinary movement can be used to check a hypothesis.

---

# 6. Multimodal physical properties

A future ReflexBrain should not learn "heavy" from a hidden field.

Possible progression:

### vision
sees approximate size/shape/motion.

### contact/proprioception
experiences:
- body deceleration;
- motor effort;
- relative slip;
- collision response.

### history
later expectation:
"things with this appearance/contact history tend to move/not move under my actuation."

This creates an actual body-relative affordance problem.

It also makes E0 mass/contact donor more meaningful.

---

# 7. Geometry and localization

Yesterday's bearing+distance percept may be too precise.

Candidate levels:

### G0
bearing sector + coarse near/mid/far.

### G1
continuous egocentric bearing + approximate depth.

### G2
accurate local relative pose.

### G3
absolute world coordinate.

G3 should be debug-only by default.

Actor-private localization may still exist, but should come from:
- proprioception;
- integrated self-motion;
- observed landmarks.

It may drift if we choose that pressure later.

Do not add drift merely for realism.

---

# 8. Vision shape candidates

Do not freeze forward cone yet.

Compare conceptually:

### V-A — omnidirectional coarse proximity
simple and stable; weak orientation meaning.

### V-B — forward field + peripheral near field
orientation matters;
keeps immediate body safety around actor;
supports directed attention/search.

### V-C — forward field only
strongest occlusion/orientation pressure;
can create pathological blindness and search artifacts.

### V-D — active gaze independent of body
powerful but introduces another control system.

Initial research preference:
**V-B is worth paper testing**, but not frozen.

---

# 9. Hearing as an orthogonal channel

Yesterday removed hearing for scope.

Reconsider.

A sparse event-based auditory channel may create cheap but valuable distinctions:

- something happened outside vision;
- direction is approximate;
- source identity may be unknown;
- actor can orient/check.

This naturally creates:
- off-screen exogenous events;
- active investigation;
- multimodal identity association;
- future social pressure.

Hearing may increase causal richness more cheaply than adding visual complexity.

Do not add speech semantics yet.

---

# 10. Perceptual leakage tests

Any proposed sensorium should face:

## PL1 — hidden ID swap
Swap World identities of visually identical entities.

Actor percept/history should remain invariant unless physical/perceptual evidence differs.

## PL2 — semantic role swap
Change research role of identical object without changing perceptible properties.

Actor must not know.

## PL3 — occlusion
Move entity while hidden.

No immediate private update.

## PL4 — reappearance ambiguity
Two similar entities could explain current percept.

Actor-private certainty must not exceed sensor evidence.

## PL5 — active check
Allow actor to move to disambiguate.

Private state should update only after new evidence.

## PL6 — physical property
Two visually identical bodies differ in mass.

Actor can only distinguish after lawful interaction/history.

This is particularly valuable for ReflexBrain.

---

# 11. Current candidate boundary

Not frozen:

World truth:
- exact physics entities.

Actor sensorium:
- body-relative synthetic visual geometry;
- occlusion;
- proprioception/contact;
- perhaps sparse event hearing.

Perceptual layer:
- temporary tracklets;
- no semantic role;
- no permanent World ID.

Memory:
- may later bind tracks/episodes into longer-lived hypotheses.

This looks like a stronger compromise than yesterday's stable semantic object percepts.

## Important cost warning

Do not turn object tracking into a computer-vision project.

A deterministic synthetic tracker may be acceptable **if its errors/authority are scoped honestly**.

The research question is cognitive/organismic grounding, not visual recognition quality.

---

# Current conclusion

Structured perception is still likely necessary for tractability.

But yesterday's structure was too close to World ontology.

The most promising boundary is:

> synthetic local physical evidence -> temporary actor-private perceptual continuity -> historical identity only when supported by actor history.

This would preserve private epistemics while allowing a richer organism than raw ray sensors alone.
