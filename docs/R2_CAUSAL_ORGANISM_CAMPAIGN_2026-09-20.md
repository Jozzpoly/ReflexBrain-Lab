## Mission

Move ReflexBrain from score-centric benchmark research toward an Owner-testable local cognitive organism without promoting R0/R1 apparatus into product architecture.

The durable research question is:

> Can a cheap local actor-private cognitive process preserve continuity, selectively assign meaning to events, and support local behaviour / cognition escalation inside a causal world without owning World truth or directly mutating the body?

## Hard campaign rules

1. **Preserve evidence, not prototype shape.**
   R0/R1 remain historical baselines and falsifiers. Their API is not R2's API.

2. **World truth != private evidence != interpretation != policy != authority.**
   Every promotion across those boundaries must remain inspectable.

3. **No hidden-World leakage.**
   Actor-relative semantic/significance claims must be grounded in actor-private evidence unless the claim is explicitly a research oracle replacing the perception layer.

4. **No Brain API before the causal organism exists.**
   Do not introduce a universal score vector, significance scalar, action distribution, or candidate interface merely for convenience.

5. **Ongoing activity is first-class.**
   New evidence is not automatically sufficient reason to abandon an existing bodily commitment.

6. **Challenge families evaluate causal distinctions, not internal labels.**
   A candidate may use scores, latent state, symbolic facts, recurrent state, or something else.

7. **Oracle before learned replacement.**
   Prove that ideal information at a boundary can produce useful behaviour before training a model to approximate that boundary.

8. **Owner-test direction is mandatory.**
   If a sequence of stages does not increase the ability to observe/provoke a living actor, treat that as campaign drift.

9. **Neutral substrate must stay weaker than donor ontologies.**
   Do not copy SPC matter lifecycle, Companion deliberation dossiers, or R1 appraisal axes into generic contracts merely because they are convenient.

10. **Temporal-ready from the beginning.**
    Challenges are episode sequences, even when a current fixture uses one frame. Snapshot classification must not silently become the R2 worldview.

## Donor lessons carried forward

### SPC / First Hearth

- reception != attention != cognition != action;
- the same event can have different legitimate significance for different residents because private causal history differs;
- unresolved meaning may need lifecycle, supersession and settlement, but those are candidate questions rather than neutral substrate fields;
- behavioural momentum matters: speech/event arrival is evidence, not automatic interruption.

### Companion-Brain-Lab

- observation requires causal provenance;
- evidence != intention != policy != authority;
- counterfactual rehearsal can produce useful future evidence without claiming a prediction or selecting a winner;
- physical/reference continuity and semantic continuity can expire independently.

### Feniks / living-world direction

- intelligence becomes necessary through world friction and intersections of independent causal lines;
- semantic cognition must eventually meet real geometry, bodies, objects, commitments and partial knowledge;
- Owner play is authoritative for product value after technical mechanisms are qualified.

### Coopege

Keep:
- stable identity;
- deterministic fixed-step / replay lessons;
- event provenance;
- persistent truth separated from active runtime.

Reject as ReflexBrain architecture:
- scalar threat table -> winner -> action;
- old GameWorld/content architecture.

## R2 campaign sequence

### Phase A — causal substrate

Create the smallest world/episode representation that can preserve:

- authoritative world events/facts;
- actor-private observations;
- actor-private causal history;
- ongoing activity;
- explicit provenance;
- time.

No learned model and no executive policy are required to pass Phase A.

### Phase B — Challenge Space v0

Build implementation-neutral causal families including:

- same event / different private history;
- same world / different actor knowledge;
- same observed motion / different causal origin;
- same message / different ongoing activity;
- actuality / conditionality / historical applicability;
- interruption -> resumption;
- supersession;
- competition;
- expectation violation.

The challenge contract must not require `threat`, `interrupt`, `attention`, `cognition` or any replacement score vector.

### Phase C — Oracle Ladder

Allow ideal research substitution at distinct boundaries:

1. perception;
2. semantic interpretation;
3. actor-relative significance;
4. executive arbitration.

These layer names are research probes, not a promise that the final brain contains four modules.

A later oracle layer normally consumes actor-private evidence only. World-truth authority is permitted only for an explicit oracle that is replacing the perception boundary.

### Phase D — deterministic living specimen

Create a small but causally rich persistent actor with:

- an ongoing multi-phase activity;
- another actor;
- at least one meaningful object;
- communication;
- dynamic physical/world events;
- private perception;
- interruption and resumption;
- causal microscope / replay.

This is the first meaningful target for Owner interaction.

### Phase E — candidate replacement

Only after oracle behaviour is useful:

- reuse R1 MiniLM/hybrid head as a baseline where relevant;
- test narrower semantic extraction;
- test relational models;
- test persistent latent local cognition;
- retain trivial rule / lexical / structured-only controls.

Promotion comes from behavioural usefulness + causal generalisation, not score accuracy alone.

## Kill / reset gates

At every major boundary ask:

> If we knew today's evidence on day one, would we still build the next stage this way?

If not, preserve the evidence and replace the architecture.

Immediate stop signals:

- new R2 code importing `ReflexScores` or treating R1 dimensions as required outputs;
- adding model capacity to improve an ontology that has not survived oracle decomposition;
- challenge definitions naming the intended internal representation instead of the causal distinction;
- repeated stages with no increasing Owner-testable capability;
- a candidate using World facts unavailable to the actor;
- event arrival directly causing global interruption/cognition without an actor-relative reason;
- neutral contracts acquiring donor-specific lifecycle/policy enums merely because one sibling project uses them.

## First implementation increment

The first R2 increment intentionally contains only:

- neutral causal contracts;
- temporal-ready, implementation-independent challenge descriptors and initial donor-derived fixtures;
- oracle boundary contracts;
- causal episode validation;
- tests proving actor-private / provenance separation.

It deliberately contains no candidate Brain interface.
