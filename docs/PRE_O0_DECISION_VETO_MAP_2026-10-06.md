# Pre-O0 Decision Veto Map — 2026-10-06

Status: **CAMPAIGN CONVERGENCE TOOL · PREVENT ANALYSIS PARALYSIS**

Purpose:

The foundations campaign has deliberately re-opened many assumptions.

Do not require theoretical closure on all of them before implementation.

---

# Class V0 — must be resolved before first serious implementation

A wrong choice here would make the specimen answer the wrong question.

## V0.1 — causal skeleton / authority

Must preserve:
- physical mediation;
- private epistemic mediation;
- exogenous causality;
- researcher separation;
- persistent internal state;
- multiple possible futures.

No debate needed on implementation details.

## V0.2 — ecology has independent causal richness

The world must contain enough persistent, partially observable, independent change that history/self-world distinction are not decorative.

Exact world mechanisms remain open.

But:
**bigger static arena alone is rejected.**

## V0.3 — perception does not expose hidden semantic/world answers

Need explicit boundary between:
- World entity;
- sensory evidence;
- perceptual continuity;
- memory hypothesis.

Exact sensor representation can remain provisional.

## V0.4 — source of organism trajectory/normativity is named and scoped

First specimen must state honestly:
- externally authored concern?
- capability regulation?
- developmental competence?
- habit?
- other?

Do not let a task silently masquerade as endogenous care.

We do not need to solve normativity universally.
We need to know what the first specimen is using.

## V0.5 — Local Brain does not use hidden scene truth

No scene-specific coordinates/routes/debug role labels.

The first policy may be simple.

## V0.6 — history can matter causally

Architecture must permit:
private history -> later ordinary behavior.

Not necessarily learned.
Not necessarily symbolic object memory.

## V0.7 — self/world research signals are preserved

Motor-side and sensory-side information must remain available so reafference/exafference can be investigated.

The first behavior need not use it yet.

## V0.8 — Owner is not heartbeat

Ecology/actor continues without Owner intervention.

# Current highest-information unresolved V0 question

Most V0 boundaries are now clear except one:

> **What source of trajectory/normativity should the first serious specimen use?**

This choice strongly affects what "meaning" can later be grounded in.

Candidate first comparison:

### Control: authored grounded concern
Transparent, easy to falsify.

### Alternative: capability-grounded internal state
A body variable changes actual future effectivity, not merely reward.

### Alternative: developmental/competence pressure
Exploration of learnable controllable relations.

### Alternative: habit/self-maintaining sensorimotor organization
No explicit external task.

Rather than deciding philosophically, F3 should paper-walk at least these alternatives through the same dynamic ecology.

# Second highest-information V0 question

> **What minimum dynamic ecology creates enough independent causal pressure?**

Strong current candidate:
small dynamic mechanical ecology with:
- persistent material topology;
- partial occlusion;
- one or two independent lawful processes;
- multiple possible routes/interactions;
- actor-independent continuation.

This world can host multiple normativity variants without being redesigned around one task.

That makes it a promising neutral substrate candidate.

# Campaign stop rule

Pre-O0 research is ready to freeze a new first implementation when:

1. all V0 boundaries are explicitly resolved or intentionally scoped;
2. at least 3 distinct normativity/trajectory candidates have been walked through the same ecology;
3. one candidate is chosen for **information gain**, not because it seems most game-like;
4. perception/body/memory are selected at reversible V1 boundaries;
5. decisive falsifiers are stated without prescribing the policy;
6. no unresolved assumption can trivially make the expected phenomenon fake.

Do not wait for philosophical certainty.

Do not implement before this threshold.
