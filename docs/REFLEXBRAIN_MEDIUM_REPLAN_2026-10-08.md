# 3. Current strategic risk

The medium has become technically interesting enough to produce its own rabbit hole:

- snapshot formats;
- storage;
- migrations;
- provenance schemas;
- browser persistence;
- import/export;
- workbench UI.

Those are easy to keep building while the actual organism remains weak.

That would recreate the project's classic failure mode in a new form:

> excellent local machinery that no longer composes into the thing we actually want.

Therefore MEDIUM-C pauses after R5 unless a concrete Workbench/Chronicle need exposes a missing causal requirement.

---

# 4. New priority

The next question is not:

> how do we store an ExperimentMoment?

It is:

> **what minimal experimental grammar would let Owner turn a surprising lived moment into a causal question without becoming a programmer?**

This belongs to MEDIUM-D.

The grammar must be designed before UI.

---

# 5. Medium / organism co-development rule

Use this loop:

1. organism/world research earns a real causal capability;
2. Habitat exposes it honestly;
3. Owner perturbs and observes;
4. Chronicle preserves a causal moment;
5. Workbench makes one nearby alternative history cheap;
6. difference generates a hypothesis;
7. hypothesis may become a frozen scientific run;
8. science updates organism/world substrate.

Stop medium implementation when:
- the next feature requires inventing an unqualified organism/world mechanism;
- a UI label would need to stand in for missing private evidence;
- exactness would require canonizing known-bad Field architecture;
- a feature exists only because it is easy to implement.
