# 1. Research question

Can one physically embodied actor carry **one explicitly authored maintain-and-monitor concern** through an independently changing material micro-world using only:

- bounded physical body actuation;
- local actor-private sensory evidence;
- actor-private temporal history;
- a small evidence-driven persistent local control process;

without hidden World truth, scene-specific routes, Owner heartbeat or semantic object APIs?

This is a **host-substrate control experiment**.

It is not:
- a learned ReflexBrain experiment;
- a proof of endogenous normativity;
- a claim of artificial life.

---

# 2. Maximum claim

If qualified:

> One unchanged local control process can maintain and re-check one authored privately evidenced physical relation under independent material change, with behavior causally mediated by body, perception and private history.

Do not promote:
- endogenous motivation;
- open-ended autonomy;
- learned semantics;
- general planning;
- general object understanding;
- final Local Brain architecture;
- production character controller;
- “life”.

# 3. World — M0-Lite

One small deterministic Rapier 2D world.

Required qualitative structure:

- open area large enough to observe locomotion;
- one occluded side area;
- one loop / alternate local route;
- one chokepoint;
- several loose dynamic bodies;
- one independent bounded mechanical shuttle/sweeper.

## Mechanical shuttle

- dynamic physical body;
- constrained to one simple physical rail/path;
- driven by bounded force/motor;
- reverses from physical end conditions, not global timer phase;
- can collide with and move loose bodies;
- collisions may change its actual timing/state;
- continues with Owner absent.

Actor receives no:
- shuttle phase;
- global schedule;
- hidden process state.

## Dynamic topology

No separate plate/gate subsystem in the first specimen.

Topology changes only because physical bodies can occupy or leave the chokepoint.

A loose body may become a real blocker.

Actor/shuttle/world contacts can later change that.

## Required lawful ecology seed

At least one qualification seed must produce, through ordinary physics and without focal actor causation:

`shuttle -> loose body / target / blocker -> changed material relation or chokepoint`.

No teleport.
No hidden scripted state transition.

Purpose:
prove that M0-Lite is genuinely independent causal pressure rather than decorative motion.

# 6. Sensorium

## P0 synthetic physical evidence

Actor-private every tick:

- body-local/proprioceptive motion;
- heading/orientation relation;
- contact summary;
- current motor demand;
- coarse egocentric local geometry;
- visible physical blobs/signatures with approximate relative bearing/range/motion;
- real occlusion.

No external-object World coordinates exposed as actor truth.

## Synthetic proprioceptive delta boundary

Private odometry integrates an explicit actor-observable body displacement/orientation delta.

Research code may derive this delta from physics truth **at the sensor boundary**.

The actor does not receive:
- arbitrary World positions of external entities;
- hidden collision-map state.

This is acknowledged perfect-proprioception scaffolding.

It is not learned localization.

## P1 temporary tracklets

P1 exists only for short perceptual continuity:

- local token while percept remains continuously/evidence-supported visible;
- adjacent-tick continuity only;
- track expires on meaningful occlusion/loss;
- reappearance creates a new current track;
- no World ID;
- no semantic kind;
- no hidden re-identification.

Long-term identity belongs to private memory/hypothesis above P1.

### P1 implementation authority

P1 association must operate only on exported P0 sensory features.

It must not use:
- collider/entity handles;
- World object identity;
- hidden trajectories.

Required unit falsifier:

> shuffle internal World entity handles while preserving the P0 sensory stream; P1 output must remain invariant.

Microscope may map track token to World entity for analysis only.

# 8. Local control

One persistent concern process.

Small generic local controllers only.

## CHECK / OBSERVE

Obtain fresh private evidence about target↔dock relation.

May:
- orient;
- approach a privately remembered local relation;
- expose occluded local space;
- inspect current perceptual evidence.

No hidden completion flag.

## bounded REACQUIRE

When expected target evidence is absent:

- check last-known vicinity;
- rotate/scan local occluded space;
- expand only through privately observed local free directions.

### Failure envelope

O-CTRL is **not** required to recover a target displaced arbitrarily anywhere in the world.

Qualification relocation/occlusion remains within a declared local search scale.

Held-out arrangements may produce honest unresolved failure.

Do not expand REACQUIRE into a general navigation/planning system merely to improve pass rate.

## RESTORE

When private evidence supports relation violation:

- derive approach/contact geometry only from:
  - current P0/P1 target evidence;
  - current visible dock evidence;
  - private remembered relations/odometry;
- approach physically;
- establish contact;
- use body motor demand to move target toward dock;
- continually observe actual consequences.

No:
- `push(target)` semantic World action;
- true target/dock pose query;
- success-by-intended-action.

If current private geometry is insufficient:
CHECK rather than solve from World coordinates.

## RECOVER

When active approach repeatedly fails:

- back off;
- reorient;
- change local contact side/approach;
- attempt bounded local detour;
- yield if unresolved.

Must avoid:
- framewise thrash;
- infinite identical pushing;
- hidden alternate-route instruction.

Debug labels may name current controller.
Labels must not drive behavior.

# 12. Five causal gates

## G1 — epistemic integrity

Paired hidden-displacement experiment:

- actor has legally acquired evidence supporting relation;
- target changes while actor cannot perceive it;
- private state remains matched before legal check;
- both runs trigger CHECK from the same private evidence-age state;
- sensory evidence diverges only when relation becomes observable;
- private belief diverges only after sensory evidence;
- irrelevant matched disturbance does not rewrite target memory.

FAIL on any hidden leak.

## G2 — material continuation and recovery

Actor legally observes relation violated.

Required:

- restoration occurs through body/contact;
- temporary obstruction does not cause thrash;
- persistent obstruction accumulates failure evidence;
- recovery uses only local/private evidence;
- no hidden alternate-route instruction;
- honest unresolved state is allowed.

FAIL on:
- teleport;
- success-by-intent;
- infinite identical pushing.

## G3 — private-history causality

Paired runs reach closely matched current sensory/body state but differ in relevant private history.

Required:

- first meaningful divergence appears in private state/controller before motor/output;
- matched irrelevant-history control does not reproduce same divergence.

Allowed claim:
private history causally affects ordinary behavior.

Not learning.

## G4 — anti-fixture transfer

Freeze controller/policy parameters.

Run:

- one development arrangement;
- at least one materially rearranged M0-Lite arrangement;
- one legal Owner-created held-out arrangement unknown when control logic was authored.

No:
- scene ID;
- new waypoint;
- scene-specific branch.

Bounded failure is acceptable.
Scene-specific code edits are not.

### Reproducible Owner arrangement

When Owner creates the held-out arrangement:

- snapshot/save initial World configuration before the run;
- record the rearrangement/intervention;
- reuse exact configuration for mechanistic follow-up.

Unknown to policy authoring does not mean lost to science.

## G5 — independent ecology value

Compare:

- normal M0-Lite;
- static ablation where independent shuttle process is disabled.

Normal world should create real:

- off-screen material change;
- stale-evidence opportunity;
- dynamic obstruction/reconfiguration;

that static control lacks.

If not:
M0-Lite is ornamental and fails its purpose.
