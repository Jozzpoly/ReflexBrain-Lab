# Current high-information unresolved questions

## Q1 — source of normativity / trajectory

Largest unresolved V0.

Candidates already paper-walked:

- authored grounded concern — clean control, task-bot risk;
- capability/homeostatic state — real stakes, safe-idle risk;
- competence/learning progress — strong developmental activity, representation/noisy-TV risk;
- sensorimotor habit — endogenous continuity, limit-cycle risk.

Current conclusion:
none should be called the answer.

Maintenance concern is demoted to **control condition**.

Capability state looks more promising as a **stake modifier** than sole motivation.

Competence and habit are strongest challengers for self-generated trajectory.

## Q2 — minimum ecology

Strongest current hypothesis:

a **small dynamic mechanical ecology** is more informative than a bigger static arena or task-specific workshop.

Required qualitative properties:
- persistent change;
- occlusion/partial observability;
- at least one independent lawful process;
- multiple possible continuations;
- actor-controllable material relations;
- delayed consequence;
- more than one timescale.

Second actor remains a comparison axis, not default.

## Q3 — perceptual abstraction

Yesterday's semantic object percepts are too strong.

Strong candidate boundary:
- synthetic local physical evidence;
- temporary actor-private perceptual tracklets;
- longer-lived identity only when history supports it;
- World IDs remain microscope-only.

This preserves tractability without handing the actor full object ontology.

## Q4 — action organization / continuation

Continuation must be a causal temporal process, not a persistent label.

Strong baseline candidate:
persistent local closed-loop controller/option with:
- private evidence;
- internal temporal state;
- progress/contradiction evidence;
- bounded recovery;
- material motor consequences.

Brooks-like parallel behaviors and habit/dynamical organization remain alternatives.

## Q5 — body morphology

E0 controller is better than its visual puck impression suggests:
bounded forward force + bounded torque + damping + real contact.

Morphology is still open.

Highest-information later A/B:
- B0 E0 disc;
- B1 minimal asymmetric oriented rigid body;
- same controller.

## Q6 — memory

Preserve:
- private provenance;
- stale knowledge;
- checked-absence principle.

Do not freeze:
- symbolic object IDs;
- exact locations;
- global scene graph.

Candidate minimal stack:
- recent sensorimotor history;
- temporary percept tracks;
- sparse relational hypotheses;
- procedural/self-model parameters.

## Q7 — adaptation

Separate:
memory, calibration, skill learning, predictive learning, representation learning, value learning, semantic learning.

Likely safe early plasticity:
- local body-model calibration;
- shadow sensorimotor forward model.

Broad semantic/value plasticity remains postponed.
