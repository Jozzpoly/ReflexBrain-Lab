# Attack A — M0 is becoming a miniature platform

Converged M0 included:
- geometry/occlusion;
- loose bodies;
- bounded shuttle;
- topology relation / gate;
- rearrangements.

Risk:
we implement multiple novel world systems before learning anything about the actor.

## Reduction

**Remove the separate plate/gate topology mechanism from the first O-CTRL specimen.**

First M0 slice should use only:

1. static walls/occlusion/loop/chokepoint geometry;
2. loose physical bodies;
3. one bounded independent mechanical shuttle/sweeper.

Dynamic topology emerges materially:

> a loose body can physically block/unblock a chokepoint, and shuttle/actor contact can change that state.

This produces:
- off-screen change;
- stale route knowledge;
- material obstruction;
- compositional causal chain;
- no semantic gate state.

A plate/gate relation becomes a later ecology pressure only if the simple material topology is insufficient.

### Verdict

**M0-Lite preferred.**

Few rules -> many intersections.
