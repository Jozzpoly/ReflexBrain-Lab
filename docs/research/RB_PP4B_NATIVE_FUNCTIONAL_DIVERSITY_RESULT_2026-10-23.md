Protocols [PP4](RB_PP4_SOURCE_FUNCTIONAL_HETEROGENEITY_ARMED_2026-10-23.md) and [PP4B](RB_PP4B_ACTUAL_VECTOR_CHANGE_ARMED_2026-10-23.md) were frozen before their executions. ## PP4: persistent bodies move little and tend to spend energy
One PP4 native t80→240 matched interval yielded **1372** exact-age/exact-member bodies from 1545 starting 2–5-cell units. Observational (median of those 1372 bodies): source 3D centroid displacement **0.013589** world units in 160 solver steps; source RMS relative-body shape change **0.007477**; mean **non-information, non-SUN cell** energy change −**0.095728**. Coarse movement differs somewhat with component size: 2-cell bodies median 0.012833, 3-cell 0.014337, 4-cell 0.050565 (37 bodies only), 5-cell 0.024382 (**n=2; uninformative**). The IOL RGB average and mean absolute saved neural output had EXACTLY the same medians t80 and t240. But this aggregation **hid raw vector changes** and could NOT support the claim that every fixed-NN output was static.

**Critical wrong-null correction:** subtracting a global translation averaged across all age-continuous source cells, including very mobile singletons/INFO-trans cells, gave an apparent ~1.76 residual, vastly larger than actual observed body movements. This reference was not physically matched to persistent 2–5-cell bodies and is NOT a neutral locomotion or external world baseline. PP4B measures a peer-unit median translation instead (close to zero). Preserve the bad diagnostic in historical PP4 protocol; do not promote it.

## PP4B: original 28-input / 28-output raw-vector audit shows REAL fixed-network response
Same-source exact t80→240 original run, **3196 native neural-network-active, non-information cells** in exact-member surviving 2–5-cell bodies. Each 28-element original `in_data`/`out_data` field was compared independently with its OWN age-advanced same physical cell.

| Genuine per-cell vector change t80→240 (1e-8 max-element threshold) | Connected 2–5-cell cohort | Solo/singleton exact cohort |
|---|---:|---:|
| Input **and** output changed | **1813 / 3196** | 31 / 258 |
| Both unchanged | **1322 / 3196** | 219 / 258 |
| Only input changed | 38 / 3196 | 3 / 258 |
| Only output changed | 23 / 3196 | 5 / 258 |

Source connected 2–5 cohort median full vector **input L1=0.001965**, median **output L1=0.003028**, output `Linf` median 0.000545, output `Linf` p75 ~0.096464. The distribution is highly mixed: one quartile exactly 0, one quartile materially different. Original source author code `sub_calculation_cell_neural_network` uses a plain tanh feed-forward network `w1,w2`; in all 3196 matched cells, both **full original serialized weight hashes were unchanged** and all book strings were unchanged at sampled endpoints. Thus observed I/O changes do NOT show lifelong weight learning. **All 3196 source IOLr/g/b light triples were unchanged** between these snapshots — not proof of total sensory blindness, since other `in_data` channels and intermediate times can vary.

The **singleton contrast** has far fewer sampled NN cells and occupies potentially different world locations, body designs and functional roles. Its weaker co-change rate is a descriptive association, not a causal proof that connections grant cognition. A 160-step 2-timepoint vector difference is not a motor policy, ecological skill or behavioral practice.

Peer-only center displacement baseline on PP4B t80→240 source execution: median body centroid shift vector effectively **zero** (~10^-7), median residual body displacement **0.013239**, close to raw observed PP4 movement. This qualitatively removes inflated whole-population-drift interpretation but is not a true physics-matched intervention/null.

## Decision
**Engineering/signal PASS:** Original source contains thousands of small physical units whose same-cell neural vectors can respond to changing stored inputs while body membership remains intact and native weights/program stay constant. It's a stronger and more differentiated mechanism than a purely inert box. **But actual movement is modest and there's no demonstrated organism-level learned value, distinct persistent lifestyle, energetic self-regulation under perturbation, real learned self/body representation, reciprocal ecology or Owner experience.**

**Dominant new gate is reproducibility of the ORIGINAL saved world/initialization.** Across otherwise similar independent source CI executions, exact at-t80/t240 counts and outcomes vary; original source `RANDOM_SEED_FLAG` may be default or input-defined. Before claiming a matched sham-vs-environment causal intervention, directly inspect original archived input flag and run the original unchanged source twice from **identical saved input** with same RNG/threads, measuring snapshot/log equality. If stochastic startup prevents matched histories, do not claim a causal perturbation from unmatched independent replicates. Only choose explicit seed control with transparent evidence and untouched motor/biology/physics after this probe. Avoid a new hybrid engine by momentum.
