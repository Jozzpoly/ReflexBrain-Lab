# Sensorimotor Lenia published-state recovery feasibility — source-data blocker
2026-10-23. This is a **catalog/file-presence audit**, not an executed pretrained pattern, not a proof of absence from the entire internet, and not a reason to train a new model.

## Published sources actually checked
1. Authors' [public repository](https://github.com/flowersteam/sensorimotor-lenia-search) pinned Git commit `f29a064f8bc18877269df56661a290fc29e485bb`; complete Git master tree had **1240 entries, not truncated**, including exactly **20 `.npy`** goal arrays and **0 `.pickle`, `.pkl`, `.pt`, `.pth` or `.npz`** pretrained weight files (in our audited tree suffix set). This is no proof that such files were never released elsewhere.
2. Authors' [Zenodo record 10211741](https://zenodo.org/records/10211741) metadata queried via public API in GitHub Actions [#39976754293](https://github.com/Jozzpoly/ReflexBrain-Lab/actions/runs/39976754293): exactly **one `flowersteam/sensorimotor-lenia-search-v1.0.1.zip`**, **225,484,622 bytes**, reported MD5 `035c7d7c35d534152c821a2e18b58551`. No archive downloaded.
3. The same archive's ZIP **central directory** was successfully reconstructed with two bounded HTTP Range requests, only **294,099 bytes transferred**, via original source CI [#39977159078](https://github.com/Jozzpoly/ReflexBrain-Lab/actions/runs/39977159078). It contains **1241 entries**, consistent with an archived root folder and essentially the same public repository tree: 73 likely data files in suffix set `.pickle/.pkl/.pt/.pth/.npz/.npy/.json`, **no pretrained .pickle or .pt files**; these were only JSON data/score and small NumPy goal arrays.
4. Parsed original repository `data/creatures_categories_init.json` (1,247,773 bytes) in [source CI #39977824444](https://github.com/Jozzpoly/ReflexBrain-Lab/actions/runs/39977824444), using public immutable GH raw SHA, no pickle loading or command execution. It contains **1835 individual creature records** grouped into **four** families (424, 612, 443, 356), each with string fields `parameters` and `stats` (1835 each). Sampled records give **absolute nonportable private-cluster references** like:
   `/gpfsscratch/rech/imi/commun/sensorimotor_lenia/resources/curi_no_imgep_init_exploration/parameters/seed1_crea00067.pickle`
   with matching `/stats/stats_seed...pickle`. These are pointers, not embedded model tensors; reviewed sample shows cluster paths. Other fields are `is_soliton/is_robust/is_moving/is_long_term_stable/observations/video`, not recoverable weights.

## Narrow conclusion
**The paper's public GitHub tree and the exact Zenodo archive examined do NOT supply the referenced original serialized `parameters` files.** Therefore a direct source-faithful replay of their *discovered, already-trained* 2025 creatures cannot currently be claimed from these assets alone. The original publication's reported robustness and online demos are legitimate outside evidence, but a video, `creatures_categories_init.json`, a reached-goal NPY array or a timestamp is NOT the trained rule + initialization state.

This is a **source availability blocker**, not a falsification of paper outcomes or evidence that no public copy may exist at another DOI or in an interactive demo bundle. We have not contacted authors, reversed engineered web-demo assets, nor searched every possible Zenodo version. We intentionally avoided pulling 225MB or unpickling unknown payloads (pickle could execute code).

## Decision
Stop speculative claims of ready-to-run 2025 pretrained creature donor. Keep the original Flow-Lenia FL0/FL1 full code findings: endogenous flow and transported local P are real, but remain **independent material mechanisms, not life**. Do not train thousands of new parameter sets merely to manufacture a flattering creature. Before any new substrate/brain integration, either locate an actually compatible published pattern with trusted source and measured long-term persistence, OR create an inexpensive world/individual perturbability test from already executable R6 originals without converting a short-lived blob to a fake organism. Otherwise choose a richer, independent ecological world process outside Lenia and reassess.

Nothing merged or deployed, R8 owner candidate unaffected; [research-only draft #92](https://github.com/Jozzpoly/ReflexBrain-Lab/pull/92).
