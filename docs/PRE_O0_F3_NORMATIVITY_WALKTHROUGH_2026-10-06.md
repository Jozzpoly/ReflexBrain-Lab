# Pre-O0 F3 Normativity Walkthrough in a Shared Dynamic Ecology — 2026-10-06

Status: **PAPER EXPERIMENT · NO IMPLEMENTATION**

Purpose:

Compare several sources of actor trajectory/normativity while holding body/world/perception assumptions as constant as reasonably possible.

This is not a final world design.

---

# Shared paper ecology — Mechanical Yard M0

The yard is intentionally not built around one actor task.

## Geometry

- one open central area;
- two side areas connected through different passages;
- one narrow passage;
- one loop route;
- real occlusion between at least two regions.

## Material entities

- several movable rigid objects with at least two mass/effectivity classes;
- visually similar objects may differ physically;
- one movable blocker can alter a passage;
- no object carries semantic role labels for the actor.

## Independent world processes

### process P1 — moving mechanism
A slow lawful mechanism periodically or state-dependently traverses part of the yard.

It can:
- move/block passage temporarily;
- displace loose objects.

Its cycle is perturbable, not a perfect global clock.

### process P2 — topology relation
A physical arrangement can open/close an alternate passage.

For example:
- weight on plate;
- counterweight;
- physical gate relation.

The mechanism is local and persistent.

### process P3 — optional local recovery field
One small area can restore a body-capability variable **only for the homeostatic variant**.

It exists physically in all comparison worlds but is behaviorally irrelevant unless the actor has that variable.

## Perception for paper comparison

Use provisional synthetic physical perception:

- proprioception/contact;
- body-relative coarse local geometry;
- temporary perceptual tracks;
- no semantic object role;
- no hidden World ID;
- occlusion.

Memory:
- recent sensorimotor history;
- temporary tracks;
- sparse relational hypotheses if a variant requires them.

Body:
- compare conceptually using same B0/B1 choice within each direct comparison.

# Variant N0 — Authored Grounded Concern

## Internal source

One explicit concern:
maintain a chosen physical relation involving one encountered landmark/object class.

Example only:
a marked local site should remain physically occupied by a compatible token.

Actor does not know current satisfaction unless perceived.

## W0 — Owner absent

Expected:
actor repeatedly checks and repairs relation.

Risk:
clean task loop.

Likely behavior:
high continuity but narrow.

## W1 — hidden world change

Strong test:
actor can act on stale private state, re-check, revise.

Good epistemic pressure.

## W2 — self vs external change

Only indirectly useful unless body/world prediction exists.

## W3 — blocked current activity

Creates clear continuation/recovery pressure.

## W4 — irrelevant perturbation

Good control:
concern should not globally reset.

## W5 — rearrangement

Can test policy generality.

## W6 — body dynamics changed

Concern stays same; local competence may fail.

Useful separation.

## W7 — history pair

Excellent:
same visible state + different concern history can produce different behavior.

## W8 — noisy process

Should mostly ignore unless it affects concern.

## W9 — Owner watches

Likely coherent but potentially repetitive/task-bot-like.

### Diagnosis

Excellent **control organism** for:
- private knowledge;
- continuation;
- scene generality;
- body/world integration.

Weak answer to:
"why does this matter to the actor?"

The answer remains:
because designer said so.

Do not hide that.

# Variant N1 — Capability-Grounded Homeostat

## Internal source

One body capability state `q`.

Requirements:
- q materially changes actual effectivity;
- q changes through real body/world coupling;
- actor actions can regulate q indirectly.

Paper example:
actuator load/thermal state.

High sustained actuation:
- raises load;
- lowers available continuous force/turn authority.

Recovery:
- happens over time and may be faster in one environmental condition/region.

No reward variable.

## W0 — Owner absent

Critical failure appears immediately:

If nothing else creates pressure, low-action rest is a strong attractor.

The organism can preserve capability by doing nothing.

This is not necessarily wrong.
But it gives weak trajectory ownership.

## W1 — hidden world change

Irrelevant unless actor has another reason to care.

Private epistemics are underused.

## W2 — self vs external change

Strong:
body capability and actuation predictions matter.

## W3 — blocked activity

But what activity?
Without another concern, there may be none.

## W4 — irrelevant perturbation

External shove may matter if it changes load/integrity.

## W5 — rearrangement

Little reason to explore arrangement.

## W6 — body dynamics changed

Very strong research case:
capability expectations become stale.

## W7 — history pair

History can matter through current body state/calibration.

## W8 — noisy process

Likely ignored.

## W9 — Owner watches

May rest or wander weakly.

### Diagnosis

Capability-grounded normativity is compelling as a **modulator/stake**, but poor as the sole source of trajectory.

This strongly suggests:
homeostasis alone should not define the first organism.

It may need:
- independent ecological pressure;
- developmental drive;
- habit;
- authored concern.

This is useful evidence against "solve normativity with energy".

# Variant N2 — Learning-Progress / Competence Explorer

## Internal source

Actor allocates action toward local sensorimotor contexts where competence/prediction/control is improving.

No fixed external maintenance task.

## W0 — Owner absent

Strong:
continuous autonomous activity emerges naturally if world offers learnable contingencies.

## W1 — hidden world change

Strong:
changed contingencies can revive learning pressure.

But:
memory of exact location may not matter unless exploration architecture uses it.

## W2 — self vs external change

Very strong:
prediction/control structure is central.

## W3 — blocked activity

Could shift exploration elsewhere.

Risk:
looks like graceful recovery while merely following learning score.

## W4 — irrelevant perturbation

Danger:
unexpected event may create artificial learning pressure.

Need distinguish learnable change from one-off surprise.

## W5 — rearrangement

Strong:
new arrangement creates new contingencies.

Potentially valuable developmental response.

## W6 — body dynamics changed

Strong:
body model/skill learning pressure naturally increases.

## W7 — history pair

Yes:
different competence history can alter exploration.

## W8 — noisy process

Decisive failure mode.

Raw prediction error would obsess over noise.
Learning progress should eventually abandon unlearnable process, but representation/context partition may still be gamed.

## W9 — Owner watches

Likely visually rich and directionally Playground-like.

Risk:
watchability generated by exploration metric rather than organism concern.

### Diagnosis

N2 is the strongest candidate for:
- self-generated ongoing activity;
- body/world learning;
- open-ended developmental trajectories.

But it is dangerously sensitive to:
- representation;
- progress estimator;
- context partition;
- noisy/unlearnable dynamics.

It should be compared as a developmental mechanism, not treated as "what the organism cares about".

# Variant N3 — Sensorimotor Habit / Self-Maintaining Organization

## Internal source

The actor develops or begins with one or several recurrent perception-action organizations.

No explicit target state.

A pattern persists because:
- current sensory consequences support the next part of the pattern;
- body/world coupling closes the loop.

Perturbation can destabilize/reorganize it.

## W0 — Owner absent

Strong:
persistent trajectory may exist naturally.

Huge risk:
limit cycle.

## W1 — hidden world change

Only matters when changed world disrupts habit.

Could produce genuine actor-relative relevance:
same object relocation matters only if it intersects current organization.

## W2 — self vs external change

Strong if habit predicts its own sensorimotor consequences.

## W3 — blocked activity

Potentially very informative:
does organization adapt around obstruction or repeatedly hit attractor boundary?

## W4 — irrelevant perturbation

Good habit should absorb/recover from transient irrelevant disturbance.

## W5 — rearrangement

Decisive:
fixed attractor may collapse;
adaptive organization may restructure.

## W6 — body dynamics changed

Decisive:
tests whether habit is tied to real body contingencies or internal timing.

## W7 — history pair

Potentially:
different prior organization states create different future trajectories.

Hard to interpret.

## W8 — noisy process

May be largely ignored unless it entrains the dynamics.

## W9 — Owner watches

Could look extremely alive even when it is only a hidden cycle.

Therefore Owner impression is particularly unsafe without cycle/falsifier analysis.

### Diagnosis

N3 is the most conceptually interesting and most dangerous.

It can create:
- endogenous continuity;
- disruption-relative significance;
- non-task trajectory.

But project history already demonstrated how cheaply recurrent dynamics can fake life.

This family deserves focused probes only if we can aggressively rule out:
- short cycles;
- phase/timing control;
- fixed return attractors;
- open-loop replay equivalence.

# Main F3 finding

No single candidate currently dominates.

More importantly:

**N0, N1, N2 and N3 solve different deficits.**

- N0 gives coherent concern but weak endogenous normativity.
- N1 gives grounded stakes but weak self-generated trajectory.
- N2 gives developmental trajectory but potentially metric-shaped "care".
- N3 gives endogenous continuity but is maximally vulnerable to fake-life dynamics.

This argues against choosing one "theory of organism" before evidence.

# Strong next experimental structure — later, not now

When implementation becomes justified, the highest-information strategy may be:

1. build one neutral dynamic mechanical ecology;
2. build one shared body/perception/history substrate;
3. run **small interchangeable action-organization/normativity specimens** on top:
   - N0 authored concern as control;
   - N2 competence explorer;
   - N3 habit candidate;
4. add N1 capability state only as an A/B stake modifier, not sole motivation.

This is **not a modular product architecture**.

It is a research design that isolates where organism-level value comes from.

# Important warning

Even this comparison can become another benchmark zoo.

The campaign should not implement four full agents.

Before code:
- simplify each to the smallest discriminative mechanism;
- choose only comparisons that can falsify a major assumption;
- discard variants whose distinctive hypothesis can be tested more cheaply.

## Current paper verdict

The old maintenance O0 should survive only as **N0 control family**.

It no longer deserves status as the project's default organism.

The strongest challengers are:
- N2 developmental sensorimotor competence;
- N3 adaptive habit/organization.

N1 capability-grounded state appears more promising as a **source of stakes/effectivity modulation** than as the sole controller of life.
