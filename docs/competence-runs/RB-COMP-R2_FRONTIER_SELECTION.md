# 1. Selection criteria

A candidate is stronger when it:

1. addresses a central ReflexBrain uncertainty;
2. uses actor-private/legal evidence;
3. can fail decisively;
4. does not depend on researcher semantic labels;
5. avoids importing another project's architecture as the answer;
6. can reuse already-qualified substrate;
7. has clear negative controls / simpler baselines;
8. produces knowledge useful across multiple future architectures;
9. does not require higher cognition or an LLM to exist first;
10. complements rather than duplicates sibling-lab work.

No numerical score is used because the dimensions are not commensurate.

# 3. Candidate B — F2 competence applicability / local-model failure

Question family:

> Can an actor tell from its own private action–consequence history when a local model or skill has stopped being trustworthy in the current causal regime?

Why this is new and ReflexBrain-native:

Living Organism R1 established:
- private history can improve a self-motion model in free motion;
- the same family can become materially harmful under contact;
- simple/analytic competitors can outperform learned variants;
- direct touch gates can reduce one cost while worsening another.

Combat adds:
- morphology/contact/material configuration changes actual action consequence;
- apparent causality must survive matched physical controls.

This creates a natural local pressure:

> **my usual action model is no longer explaining what my body is doing.**

This pressure is actor-relative and private.

It does not require:
- a named goal;
- a World-side blocked label;
- a reward scalar;
- an LLM;
- an explicit R6-style Matter object.

Primary risk:

It is dangerously easy to rename:
- prediction error,
- surprise,
- residual,
as "meaning".

R2 therefore rejects a trivial test:
> high residual = salient.

The first run must ask whether private competence evidence predicts **actual decision reliability**, not merely whether an environment changed.

Judgement:

**SELECT AS FIRST ORGANISM-FRONTIER FALSIFIER.**

# 8. RB-F2/P0 candidate experiment

This section freezes the **question shape**, not implementation architecture.

## Core distinction

Do NOT ask:

> can prediction residual detect a wall/contact?

That would reward environment classification.

Ask:

> **before taking the next action, can private evidence predict whether trusting the local model will lead to a worse action choice than a simpler fallback?**

This ties "competence" to consequence.

---

## Donor shape

Use a small embodied body-motion/action-choice specimen.

Required private inputs:
- recent own motor demand;
- recent body-local proprioceptive motion;
- optionally legal private touch only as a separate baseline/control, not primary model input.

Forbidden model input:
- World position;
- collider identity;
- contact handle;
- wall flag;
- blocked label;
- true external force;
- scenario label.

Host truth may evaluate outcome only.

---

## Frozen model roles

### Local model M
A frozen short-horizon self-motion/action model.

Architecture is not privileged.

Candidate implementation may begin with:
- the audited simple Living Organism body-history donor;
- or an even simpler refit on canonical body dynamics.

The scientific question must survive replacing M.

### Fallback F
A strong simpler local strategy.

Examples:
- no-history model;
- conservative motor-only calibration.

Fallback must be frozen before qualification.

### Reliability evidence R
Derived only from **past private prediction vs observed consequence**.

No current World regime label.

R does not equal meaning.

It is only a candidate predictor of whether M is currently safe/useful to trust.

# 9. P0 protocol shape

Whole episodes split by scene/seed, never random windows from the same trajectory across train/test.

Families should include at least:

### Familiar free dynamics
M should remain useful.

### Unseen free-space disturbance
External force/dynamics shift without contact.

Purpose:
test whether R merely detects any novelty.

### Constraint/contact regime
Body dynamics become qualitatively different.

Purpose:
test the known donor failure.

### Recovery back to free dynamics
Purpose:
test whether R can recover instead of permanently declaring incompetence.

At each eligible decision point:

1. source state fixed;
2. compute M choice;
3. compute fallback F choice;
4. record R **before future forks are observed**;
5. fork physics under M and F actions;
6. evaluate bounded physical consequence;
7. label only for researcher analysis:
   - M better;
   - tie;
   - F better.

Primary target:

> does R predict **M-vs-F decision regret/reliability** on held-out episodes?

Not:
> does R classify contact?

---

# 10. Strong controls

Required baselines for reliability prediction:

- recent speed magnitude only;
- recent acceleration/change only;
- direct private touch only, where available;
- time since last touch;
- last motor demand;
- a constant "always trust M";
- a constant "always use F".

If R does not outperform simple body/touch signals, it does not earn a new organ.

A learned reliability model is not required for P0.

Start with the simplest calibrated private statistic.

---

# 11. P0 falsifiers

FAIL if:

- residual/reliability cannot predict model regret beyond simple private baselines;
- signal only works on the exact training/contact geometry;
- unseen force produces identical "failure" even though M remains the better action choice;
- recovery never restores trust;
- touch alone explains all benefit;
- thresholds require tuning on qualification set;
- host contact/regime labels leak into decision path.

INCONCLUSIVE if:
- M rarely differs from F;
- outcome metric does not distinguish good/bad action;
- body/action repertoire is too trivial to expose competence loss.

No rescue by:
- adding semantic blocked state;
- adding reward;
- adding a larger NN;
- importing Combat scene ontology;
- adding LLM judgement.

---

# 12. Maximum P0 claim

PASS would establish only:

> a local actor can derive private temporal evidence that predicts when one bounded local action model should or should not be trusted relative to a frozen simpler fallback.

It would NOT establish:
- meaning;
- salience;
- curiosity;
- owned goals;
- general confidence;
- natural escalation;
- learned ReflexBrain;
- safe contact handling.

But it would create a defensible substrate for later questions:

- what should the actor do when competence is unreliable?
- seek information?
- switch skill?
- create an unresolved local reason?
- escalate?

# 13. Why G5A first

R2 deliberately keeps G5A ahead of F2 implementation.

Reason:

G5A tests whether the world can create **actor-private historical pressure without researcher heartbeat**.

If this foundation fails, F2 may still be interesting local-control research but would not repair the missing ecology/life substrate.

Therefore:

> **Foundation first in execution, organism frontier first in design.**

This is the two-speed strategy in operational form.
