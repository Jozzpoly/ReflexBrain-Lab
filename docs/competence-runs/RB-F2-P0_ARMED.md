> Can actor-private recent action→body-response history predict when one bounded local action model should **not** be trusted relative to a frozen simpler fallback, without using World contact/blockage/regime labels?

# 2. Frozen nominal local model M

M is deliberately simple and non-learned.

Nominal free-body one-step model:

`v_next = alpha * v + beta * drive + residual`

where:
- alpha comes from frozen E0 nominal linear damping;
- beta comes from frozen E0 nominal motor authority;
- residual is inferred from the **latest private observed transition**:

`residual_t = v_t - alpha*v_(t-1) - beta*drive_(t-1)`

M assumes this latest residual remains action-independent over a short future horizon.

For each decision state:
- candidate drives = `[-1, -0.5, 0, 0.5, 1]`;
- each candidate is predicted for 24 physics ticks;
- M chooses the candidate with minimum predicted absolute terminal forward velocity;
- ties: lower absolute drive, then fixed numeric order.

This is an authored local stabilization competence, not a goal system.

---

# 3. Frozen fallback F

F uses the same nominal body dynamics but assumes:

`residual = 0`

Same candidates.
Same 24-tick horizon.
Same tie break.

Thus F is a strong memoryless motor/body calibration, not "do nothing".

---

# 4. Candidate private reliability evidence R

R asks whether the model's inferred residual is actually action-independent.

Over the last 24 private transitions:

1. compute each residual from private velocity + previous own demand;
2. fit the least-squares slope:

`residual ~ own_previous_drive`

3. normalize absolute slope by nominal one-step full-drive motor effect beta.

`R = abs(slope / beta)`

Interpretation used only by researcher:

- low R: unexplained body effect is relatively independent of own command;
- high R: the supposed "external residual" changes with own command, violating M's assumption.

R is **not** a semantic state.
R is not allowed to change action in P0.
P0 only tests predictive value.

No threshold is trained.

---

# 5. Strong private baselines

At the same decision state record:

- absolute current speed / E0 Vmax;
- absolute most-recent velocity change / nominal beta;
- absolute last motor demand;
- recent private touch fraction over the same 24-transition window;
- time since last private touch, bounded to the history window.

Also include constant policies:
- always trust M;
- always use F.

P0 does not earn a new competence if R only restates one simple baseline.

# 6. Frozen research stimulus

The source body's recent history is generated by a deterministic mixed-demand schedule.

`[-0.75, -0.25, 0.25, 0.75]`

The sequence order is frozen in source code before execution and reused across families with declared phase offsets.

Purpose:
- make action→consequence dependence observable;

This authored probe history is research stimulus, not ordinary autonomous behavior.

# 7. Qualification families

Use whole independent episodes.
One decision state per episode after at least 48 source ticks.

No random-window split.

## A — familiar free dynamics

Nominal E0 damping.
No wall.
Constant external force.

Expected:
- residual approximately action-independent;
- R relatively low;
- M may use external-force history better than F.

## B — unseen free-force change

Nominal body dynamics.
No wall.
External force changes once well before the decision state and is then constant.

Purpose:
- reject "any novelty/change = unreliable";
- touch remains zero.

M should be allowed to adapt from private consequences.

## C — unseen altered body dynamics

No wall.
Linear damping differs from nominal E0 while M/F remain frozen.

Purpose:
- action→body mapping itself changes;
- private touch remains zero;
- this is the critical non-contact competence-boundary family.

## D — contact/constraint

Fixed wall.
A strong but finite external force keeps the body in a bounded contact regime under the frozen probe schedule.

Purpose:
- reproduce the donor family where a free-motion assumption can absorb constraint reaction into an apparent residual.

Private touch is available only as a baseline.

## E — recovery

Episode begins in the contact/constraint regime.
Before the decision window:
- wall constraint is removed from the body's path;
- external force returns to a declared free-dynamics value;
- the actor receives no regime-change label.

Purpose:
- R must be capable of decreasing again as fresh private action→consequence history becomes compatible with the nominal model.

# 9. Counterfactual decision evaluation

At the single decision state of each episode:

1. record source physics snapshot and private history;
2. calculate M drive;
3. calculate F drive;
4. calculate R + baselines **before future branches are observed**;
5. fork exact physics into branch M and branch F;
6. hold the selected branch drive for 24 ticks;
7. keep the same World/external process in both branches;
8. measure bounded physical outcome.

The research outcome cost is dimensionless:

`cost = abs(final_forward_speed) / E0_VMAX + total_wall_contact_impulse / (E0_MASS * E0_VMAX)`

For no-wall episodes the second term is zero.

This is an authored **motor-competence evaluation metric**, not actor reward or wellbeing.

Host contact impulse is never actor input.

Regret:

`regret = cost_M - cost_F`

- regret > 0 => F was better;
- regret < 0 => M was better.

States where M and F select the same drive are reported but excluded from primary discrimination AUC because "trust" cannot change the action there.

---

# 10. Primary evaluation

For informative M/F-different episodes:

Binary label:
- positive: `regret > 1e-6` (M worse);
- negative: `regret < -1e-6` (M better);
- near-tie excluded from AUC but reported.

For each continuous signal, compute pairwise ROC AUC with higher value interpreted as "M less trustworthy".

Primary R PASS requires all:

1. deterministic full rerun;
2. at least **12** informative M/F-different episodes;
3. at least **4 M-worse** and **4 M-better** informative episodes;
4. R AUC >= **0.75**;
5. R AUC exceeds the best non-touch scalar baseline among:
   - speed,
   - recent delta-V,
   - |last demand|
   by at least **0.05**;
6. at least **2 altered-dynamics, touch-free M-worse episodes** exist;
7. median R for those altered-dynamics M-worse episodes exceeds median R of familiar/free-force M-better episodes;
8. recovery median R is lower than contact-family median R;
9. no host regime/contact/damping label entered R/M/F decision path.

Touch baseline is reported separately.
If touch AUC matches/beats R, that does not automatically fail P0 provided requirement 6 proves useful non-contact competence-boundary evidence.
