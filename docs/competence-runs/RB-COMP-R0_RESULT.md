# 3. Strongest cross-lab findings

## Finding A — perception density is not meaning

LLM Live NPC PR #159:

After authored opening completion:
- 3,600 actual World ticks;
- player genuinely enters several residents' private sight;
- zero new owned reasons;
- zero new matters;
- zero resident movement;
- zero provider calls.

Thus:

> more events / more seeing / more proximity does not by itself create actor-owned significance.

This directly constrains ReflexBrain.

---

## Finding B — the same current event can matter differently because of private history

LLM Live NPC PR #156 and #158:

- an object becoming privately available can reactivate an existing blocked concern;
- the same availability without prior concern is neutral;
- a person's re-entry can matter only for the resident with an existing standing relation;
- the same physical re-entry without relation is neutral.

Thus:

> relevance can be relational and history-dependent without being identical to perception.

This is one of the closest external donors to ReflexBrain's original target.

---

## Finding C — owned temporal relation can create pressure without a cognition heartbeat

LLM Live NPC PR #160:

A typed standing commitment with an accepted revisit time can later produce exactly one private unresolved question from World time, without:
- automatic action;
- speech;
- provider call;
- global timer-created meaning.

Thus:

> time can become locally significant through an already-owned relation.

This is highly relevant to continuous local life.

---

## Finding D — local competence is domain-bounded

Living Organism Runtime A reports strong free-motion prediction that degrades or becomes harmful in contact conditions.

Combat Lab independently shows:
- morphology changes physical action envelope;
- contact/material configuration changes consequences;
- apparent causal effects can disappear under matched controls;
- local response can change material afterstate without producing a new affordance/opportunity for another actor.

Thus:

> a local skill/model may be competent in one domain and misleading in another.

A ReflexBrain-scale system may need to represent not only "what matters" but **where local competence stops being trustworthy**.

This remains scout-derived until Living Organism branch is independently qualified.

---

## Finding E — higher cognition must be constrained by executable local capability

LLM Live NPC PR #161:

A semantic contract must be rejected if the actual resident World/runtime cannot service it.

Together with broader R6 evidence that more cognition does not automatically produce useful embodied action:

> higher cognition cannot be treated as authority over capabilities that the local organism does not possess.

This supports capability-aware escalation rather than LLM heartbeat control.
