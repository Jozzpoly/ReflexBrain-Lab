## Jak odzyskać usuniętą gałąź

```sh
git clone https://github.com/Jozzpoly/ReflexBrain-Lab.git
cd ReflexBrain-Lab
git fetch --tags
git switch -c recover-r1 refs/tags/archive/reflexbrain-2026-11-10/experiment/r1-paired-reason-head-v1
```

To przykładowe odtworzenie dawnego brancha R1, w tym wszystkich jego przodków. Dla innego eksperymentu podmień ostatnią część znacznika na nazwę z JSON.

**Nie usuwaj zbioru archiwalnych tagów**. Same SHA zapisane w JSON nie chronią przed późniejszym odśmiecaniem nieosiągalnych obiektów Git. Tag na GitHubie też nie jest niezależnym backupem poza GitHubem.
