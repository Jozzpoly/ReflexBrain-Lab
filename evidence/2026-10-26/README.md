## Reproduction — one concrete debt partially paid

File: [`replay-c5-g0.cjs`](replay-c5-g0.cjs). Requires Node 22+ and two exact original **Gloopipelago** source files from commit `91d924842cb2d3f460336f4147fa8b72f122da5b`. It does not install dependencies, touch game code or network at runtime. It refuses mismatched **Git blob SHA-1** for both files. In a local clone of the pinned upstream:

```bash
node replay-c5-g0.cjs /path/to/Gloopipelago/src/core/v1-mirror.mjs /path/to/Gloopipelago/src/core/m4-ecological-mosaic.mjs
```

Replays first native parent birth from each seed, forks 6 arms × 600 ticks, verifies complete original-vs-patched-allow actor/food/RNG/source counts, and asserts exact one-bit history first-divergence step **441, 483, 242, 466, none**. Outputs per-seed JSON with birth and energy differences. **Same runner core was re-executed directly against fetched exact GitHub sources in an isolated V8 environment and passed five seeds on 26 Oct. Node CLI on a separate local clone has *not* yet been executed in this session**. Classify as *archived source-replay runner*, not independent Node CI PASS.

**Other C4/C5 transient V8 experimental methods remain described in PR #6 but their full exact runners are NOT yet archived or independent CI-qualified.** Do not pretend this one file reproduces all 10,019 meals or the 40 motor forks. Future independent replication may use these frozen evidence comments, with a strict reproduced-vs-reported distinction.
