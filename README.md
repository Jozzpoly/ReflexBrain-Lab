## Current state

Persistent Playground v1 is Owner evidence that the **persistent embodied-organism direction is worth pursuing**. Its architecture is not privileged.

E0.0 remains a qualified **body/microscope donor**, not an organism milestone.

The old 2026-10-05 `O0_PERSISTENT_MICRO_ECOLOGY_CONTRACT` is preserved as a historical candidate under audit. Draft PR #5 is **not** the active implementation mandate.

The foundations campaign has converged on a first research sequence, but no new organism code has been started.

### First control occupant — O-CTRL

O-CTRL is deliberately an authored control agent, not a claim of endogenous life.

Current candidate substrate:

- **M0 Dynamic Mechanical Yard** — small persistent physical ecology with occlusion, loose bodies, one bounded independent mechanical process and one compositional topology relation;
- **B1 minimal asymmetric rigid body** as primary morphology, with the E0 **B0 disc** retained as a mandatory control;
- **P0 local physical sensing + P1 temporary perceptual tracklets**, with no World IDs or semantic object roles;
- private temporal history with stale/checked knowledge;
- **C-A persistent local closed-loop concern/controllers** driven only by actor-private evidence;
- preserved motor-side and sensory-side signals for self/world research;
- researcher-only causal microscope.

The T0 control concern is intentionally simple and explicit:

> maintain one perceptually distinctive movable body in a preferred physical relation with one distinctive physical dock/landmark.

This concern is a **control scaffold**, not a theory of normativity.

### Second occupant — O-DEV

After O-CTRL qualifies the substrate, remove the authored concern and test a developmental competence / learning-progress challenger on the same body/world/perception/history substrate.

O-DEV is intended to ask whether self-directed sensorimotor learning creates qualitatively richer actor-owned trajectory than the authored control, while precommitting against old Playground failures such as wall-clinging, noisy/unlearnable attraction and representation artifacts.

## Hard boundaries

- Owner input is not the organism heartbeat.
- World truth, sensory evidence, private history/hypothesis and debug truth are distinct.
- Body/world consequences remain material.
- Hidden World state must not enter Local Brain decisions.
- Continuation is a causal temporal process, not a label.
- Machine PASS never promotes an Owner experiential/product claim.
- The microscope explains the organism; it must not become the organism.
- Learned ReflexBrain work resumes only when the host naturally produces repeated residual semantic pressure with a real downstream consumer.
